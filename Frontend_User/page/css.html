1. CSS Syntax and Selectors - របៀបសរសេរ CSS និងការជ្រើសរើស

CSS (Cascading Style Sheets) ត្រូវបានប្រើដើម្បីកំណត់រចនាប័ទ្ម និងប្លង់នៃទំព័រគេហទំព័រ។ វាដើរតួនាទីយ៉ាងសំខាន់ក្នុងការរចនាគេហទំព័រ ហើយអ្នកអាចគ្រប់គ្រងវាបានតាមរយៈ selectors ដែលប្រើដើម្បីជ្រើសរើសធាតុ HTML។

1.1 CSS Syntax - របៀបសរសេរ CSS

ក្បួន CSS មានការជ្រើសរើស (selector) និងប្លុកប្រកាស (declaration block) ដែលមានលក្ខណៈសម្បត្តិ (property) និងតម្លៃ (value)។

ឧទាហរណ៍ HTML:

<p>នេះជាអត្ថបទគំរូ</p>

ឧទាហរណ៍ CSS:

p { color: blue; font-size: 16px; }
គន្លឹះ៖ រាល់ declaration ត្រូវបញ្ចប់ដោយសញ្ញា ; និងត្រូវដាក់នៅក្នុងសញ្ញា { }។

1.2 Types of Selectors - ប្រភេទនៃការជ្រើសរើស

1.2.1 Element Selector

ជ្រើសរើសធាតុ HTML តាមឈ្មោះ tag របស់វា។

h1 { color: #2563eb; } p { font-size: 16px; }

1.2.2 Class Selector

ជ្រើសរើសធាតុដែលមាន class ជាក់លាក់ ដោយប្រើសញ្ញា .

.highlight { background: yellow; }

1.2.3 ID Selector

ជ្រើសរើសធាតុដែលមាន id ជាក់លាក់ ដោយប្រើសញ្ញា #

#header { background: #333; }

1.2.4 Universal Selector

ជ្រើសរើសធាតុទាំងអស់ក្នុងទំព័រ ដោយប្រើសញ្ញា *

* { margin: 0; padding: 0; }

1.2.5 Attribute Selector

ជ្រើសរើសធាតុតាម attribute របស់វា។

a[target="_blank"] { color: red; }

1.2.6 Pseudo-class Selectors

ជ្រើសរើសធាតុក្នុងស្ថានភាពពិសេស ដូចជា :hover, :focus ជាដើម។

a:hover { color: red; }

1.2.7 Pseudo-element Selectors

ជ្រើសរើសផ្នែកមួយនៃធាតុ ដូចជា ::before, ::after

p::first-line { font-weight: bold; }

2. CSS Colors and Backgrounds - ពណ៌ និងផ្ទៃខាងក្រោយ

2.1 Color Values

ការកំណត់ពណ៌ក្នុង CSS អាចធ្វើឡើងតាមច្រើនទម្រង់៖

2.1.1 Hexadecimal
p { color: #ff5733; }
2.1.2 RGB
p { color: rgb(255, 87, 51); }
2.1.3 RGBA

RGB បូកបន្ថែមតម្លៃ Alpha (0 ដល់ 1) សម្រាប់ភាពថ្លា (Transparency)។

p { color: rgba(255, 87, 51, 0.5); }
2.1.4 HSL
p { color: hsl(9, 100%, 60%); }
2.1.5 HSLA
p { color: hsla(9, 100%, 60%, 0.7); }

2.2 Backgrounds

2.2.1 background-color
body { background-color: #f4f4f4; }
2.2.2 background-image
div { background-image: url('bg.jpg'); }
2.2.3 background-position
div { background-position: top right; }
2.2.4 background-repeat
div { background-repeat: no-repeat; }
2.2.5 background-size
div { background-size: cover; }

3. CSS Box Model - ទម្រង់ប្រអប់ CSS

3.1 Box Model Areas

គ្រប់ធាតុ HTML ទាំងអស់ត្រូវបានបង្កើតឡើងដោយប្រអប់មួយដែលមាន ៤ ផ្នែក៖

  • 3.1.1 Content: ផ្ទៃបង្ហាញអត្ថបទ រូបភាព ឬវីដេអូ។
  • 3.1.2 Padding: ចន្លោះទំនេររវាង Content និង Border។
  • 3.1.3 Border: ជញ្ជាំង ឬព្រំប្រទល់ព័ទ្ធជុំវិញ Padding។
  • 3.1.4 Margin: ចន្លោះទំនេរខាងក្រៅ Border សម្រាប់ឃ្លាតពី Element ផ្សេងទៀត។

3.2 box-sizing

កំណត់របៀបគណនាទំហំ Width និង Height សរុបរបស់ Element។

* { box-sizing: border-box; /* រាប់បញ្ចូល padding/border ក្នុងទំហំសរុប */ }

4. CSS Typography - ការកំណត់រចនាប័ទ្មអក្សរ

4.1 Font Properties

  • 4.1.1 font-family: កំណត់ប្រភេទពុម្ពអក្សរ (ឧ. 'Poppins', sans-serif)
  • 4.1.2 font-size: កំណត់ទំហំអក្សរ (px, rem, em)
  • 4.1.3 font-weight: កំណត់កម្រាស់អក្សរ (normal, bold, 100-900)
  • 4.1.4 font-style: កំណត់ទម្រង់អក្សរ (normal, italic)
  • 4.1.5 line-height: កំណត់កម្ពស់ចន្លោះជួរអក្សរ

4.2 Text Alignment

p { text-align: center; }

4.3 Text Decoration

a { text-decoration: none; }

4.4 Text Transform

h1 { text-transform: uppercase; }

5. CSS Layouts - ការរៀបចំប្លង់ទំព័រ

5.1 Display Property

  • 5.1.1 block: យកប្រវែងទទឹងពេញ (100%) និងចាប់ផ្តើមជួរថ្មី។
  • 5.1.2 inline: យកប្រវែងទទឹងតាមទំហំ Content និងមិនចាប់ជួរថ្មីទេ។
  • 5.1.3 inline-block: ដូច inline ប៉ុន្តែអាចកំណត់ width និង height បាន។
  • 5.1.4 none: លាក់ Element ចេញពីទំព័រទាំងស្រុង។

5.2 Flexbox

ប្រព័ន្ធរៀបចំប្លង់ដែលបត់បែនបានតាម Row ឬ Column។

.container { display: flex; flex-direction: row; justify-content: space-between; align-items: center; }

5.3 CSS Grid

ប្រព័ន្ធរៀបចំប្លង់ ២ ទិស (Two-dimensional Grid)។

.grid { display: grid; grid-template-columns: repeat(3, 1fr); grid-gap: 10px; }

5.4 Positioning

  • 5.4.1 static: ទីតាំងដើមតាមលំហូរធម្មតានៃ Document។
  • 5.4.2 relative: Positioned relative ទៅនឹងទីតាំងដើមរបស់វា។
  • 5.4.3 absolute: Positioned relative ទៅនឹង Parent ដែលមាន Position។
  • 5.4.4 fixed: នៅថេរធៀបនឹង Viewport (អេក្រង់) ទោះ Scroll ក៏ដោយ។
  • 5.4.5 sticky: នៅជាប់អេក្រង់តាម Scroll Position។

6. CSS Borders and Shadows - ជញ្ជាំង និងស្រមោល

6.1 Border Properties

កំណត់កម្រាស់ រចនាប័ទ្ម និងពណ៌របស់ Border៖

.box { border: 2px solid #2563eb; }

6.2 Border Radius

ធ្វើឱ្យជ្រុងរបស់ Element មានភាពកោង ឬជារង្វង់៖

.card { border-radius: 12px; } .avatar { border-radius: 50%; /* ធ្វើជារង្វង់មូល */ }

6.3 Box Shadow

បន្ថែមស្រមោលទៅលើ Element (offset-x, offset-y, blur, spread, color)៖

.card { box-shadow: 0 4px 15px rgba(0, 0, 0, 0.1); }

7. CSS Transitions and Animations - ចលនា និងអាណានីមេស្យុង

7.1 Transitions

ផ្លាស់ប្តូរតម្លៃ CSS ដោយរលូននៅពេលមាន Hover ឬការផ្លាស់ប្តូរ State៖

.btn { background-color: #2563eb; transition: background-color 0.3s ease; } .btn:hover { background-color: #1d4ed8; }

7.2 Keyframe Animations

បង្កើតចលនាផ្លាស់ប្តូរស៊ាំញ៉ាំដោយប្រើ @keyframes៖

@keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } } .element { animation: fadeIn 1s ease-in-out; }

8. CSS Responsive Web Design - ការរចនាសម្របតាមទំហំអេក្រង់

8.1 Viewport Meta Tag

ចាំបាច់ត្រូវដាក់ក្នុង HTML <head> ដើម្បីឱ្យគេហទំព័រសម្របតាមទូរស័ព្ទ៖

<meta name="viewport" content="width=device-width, initial-scale=1.0">

8.2 Media Queries

កំណត់ Style ដោយផ្អែកលើទំហំ Screen Width៖

@media (max-width: 768px) { .sidebar { display: none; /* លាក់ sidebar លើ Screen តូច */ } }

9. CSS Pseudo-classes & Elements

9.1 Pseudo-classes

ជ្រើសរើស Element ផ្អែកលើ State របស់វា៖

  • :hover - នៅពេល Mouse Hover លើ Element
  • :focus - នៅពេល Element កំពុងត្រូវបានជ្រើសរើស (ឧ. Input field)
  • :nth-child(n) - ជ្រើសរើស កូនទី n របស់ Parent

9.2 Pseudo-elements

ជ្រើសរើស និង Styling ផ្នែកណាមួយនៃ Element ៖

  • ::before - បញ្ចូលអត្ថបទ/Style មុន Content
  • ::after - បញ្ចូលអត្ថបទ/Style បន្ទាប់ពី Content

10. Positioning and Z-index

Positioning: ប្រើសម្រាប់គ្រប់គ្រងទីតាំងទីកន្លែងបង្ហាញធាតុនៅលើទំព័រ។

Z-index: គ្រប់គ្រងលំដាប់នៃការជាន់គ្នា (Stacking order) នៃធាតុដែលបានកំណត់ position។ តម្លៃកាន់តែធំ នឹងស្ថិតនៅលើគេ។

.modal { position: fixed; z-index: 999; }

11. CSS Variables - អថេរ CSS

Custom properties សម្រាប់ផ្ទុកតម្លៃ និងយកទៅប្រើឡើងវិញ ដើម្បីងាយស្រួលគ្រប់គ្រង Theme។

:root { --primary-color: #3498db; } h1 { color: var(--primary-color); }

12. CSS Specificity and Cascade

Specificity: កម្រិតអាទិភាពដើម្បីសម្រេចថាតើ Rule មួយណាត្រូវយកមកប្រើប្រាស់៖

Inline styles > IDs > Classes / Pseudo-classes > Elements

Cascade: របៀបដែល CSS អនុវត្តបន្ទាត់កូដនៅពេលមានការជាន់គ្នា/ផ្ទុយគ្នា។

13. CSS Functions - មុខងារ CSS

calc()

width: calc(100% - 50px);

var()

color: var(--primary-color);

clamp()

font-size: clamp(14px, 5vw, 24px);

14. CSS Grid Layout - ប្លង់បែប Grid

CSS Grid ផ្តល់នូវប្រព័ន្ធរៀបចំប្លង់ពីរទិសដៅ (Two-dimensional Grid System) ដែលងាយស្រួលបង្កើត layout ស្មុគស្មាញ។

.grid-container { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; }

15. Flexbox Layout Deep Dive

Flex Container: Container ដែលមានកំណត់ display: flex; ឬ display: inline-flex;

Flex Items: ធាតុទាំងឡាយដែលស្ថិតនៅខាងក្នុង Flex Container។

Main Axis and Cross Axis:

  • Horizontally (Main Axis): អ័ក្សចម្បងសម្រាប់តម្រឹមធាតុតាមជួរដេក (justify-content)។
  • Vertically (Cross Axis): អ័ក្សកែងសម្រាប់តម្រឹមធាតុតាមជួរឈរ (align-items)។
.flex-container { display: flex; justify-content: center; /* Main Axis */ align-items: center; /* Cross Axis */ }
