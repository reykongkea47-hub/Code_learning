1. JavaScript Introduction - ការណែនាំ JS

1.1 អ្វីជា JavaScript?

JavaScript គឺជាភាសា programming language ដែលប្រើសម្រាប់បន្ថែម interactivity ទៅគេហទំព័រ។

📘 ការពន្យល់៖ JavaScript ដំណើរការនៅលើ browser (client-side)។ វាអាចកែ DOM, ឆ្លើយតបនឹង events, ទាញ data ពី server និងច្រើនទៀត។ ប្រើសម្រាប់៖
  • Web Frontend — Interactive UI
  • Backend — Node.js
  • Mobile Apps — React Native
  • Desktop Apps — Electron

1.2 ការដំឡើង

  • Browser — Chrome, Firefox (F12 → Console)
  • Node.js — សម្រាប់រត់ JS ក្រៅ browser
  • VS Code — Editor ពេញនិយម
<!-- បញ្ចូល JS ក្នុង HTML --> <script src="app.js"></script> <!-- ឬ inline --> <script> console.log("Hello!"); </script>

1.3 Console

console.log("Hello, World!"); // បង្ហាញសារ console.error("Error!"); // កំហុស console.warn("Warning!"); // ព្រមាន console.table([1, 2, 3]); // តារាង

1.4 Syntax

// Statement បញ្ចប់ដោយ ; let name = "Dara"; console.log(name); // Comments // Single line /* Multi-line */

2. Variables & Data Types

2.1 var / let / const

var old = "ចាស់"; // Function scope (មិនគួរប្រើ) let age = 20; // Block scope (អាចផ្លាស់ប្តូរ) const PI = 3.14; // Block scope (មិនអាចផ្លាស់ប្តូរ)
📘 ការពន្យល់៖: ប្រើ const ជាលំនាំដើម។ ប្រើ let តែនៅពេលត្រូវការផ្លាស់ប្តូរតម្លៃ។ កុំប្រើ var ព្រោះវាមានបញ្ហា scope។

2.2 Data Types

  • Primitive: string, number, boolean, null, undefined, symbol, bigint
  • Reference: object, array, function
let name = "Dara"; // string let age = 20; // number let isActive = true; // boolean let nothing = null; // null let undef; // undefined let user = { name: "Dara" }; // object let nums = [1, 2, 3]; // array

2.3 Type Coercion

"5" + 3 // "53" (string) "5" - 3 // 2 (number) 5 == "5" // true (loose) 5 === "5" // false (strict)

2.4 Template Literals

let name = "Dara"; let greeting = `Hello, ${name}!`; console.log(greeting); // Hello, Dara!
📘 ការពន្យល់៖: Template literal ប្រើ ` (backtick) និង ${} សម្រាប់បញ្ចូល expression។ វាងាយស្រួលជាង concatenation ដោយ +។

3. Operators

3.1 Arithmetic

5 + 3 // 8 10 - 4 // 6 3 * 4 // 12 10 / 3 // 3.333... 10 % 3 // 1 (modulo) 2 ** 3 // 8 (power)

3.2 Comparison

5 == "5" // true (loose) 5 === "5" // false (strict) 5 != "5" // false 5 !== "5" // true 5 > 3 // true 5 <= 5 // true
📘 ការពន្យល់៖: ត្រូវប្រើ === និង !== ជានិច្ច ដើម្បីជៀសវាង bug ពី type coercion។ == នឹងបំប្លែង type ដោយស្វ័យប្រវត្តិ។

3.3 Logical

true && false // false (AND) true || false // true (OR) !true // false (NOT)

3.4 Ternary

let result = age >= 18 ? "Adult" : "Minor";

4. Control Flow

4.1 if / else

if (age >= 18) { console.log("Adult"); } else if (age >= 13) { console.log("Teen"); } else { console.log("Child"); }

4.2 switch

switch (day) { case 1: console.log("Monday"); break; case 2: console.log("Tuesday"); break; default: console.log("Unknown"); }

4.3 Loops

// for loop for (let i = 0; i < 5; i++) { console.log(i); } // while loop let j = 0; while (j < 5) { j++; } // do-while do { j++; } while (j < 10);

4.4 for...of / for...in

// for...of — តម្លៃ for (const num of [1, 2, 3]) { console.log(num); } // for...in — key const user = { name: "Dara", age: 20 }; for (const key in user) { console.log(key, user[key]); }
📘 ការពន្យល់៖: for...of ប្រើសម្រាប់ array (តម្លៃ)។ for...in ប្រើសម្រាប់ object (key)។ កុំច្រឡំ!

5. Functions

5.1 Function Basics

// Function declaration function greet(name) { return `Hello, ${name}!`; } // Function expression const add = function(a, b) { return a + b; };

5.2 Arrow Functions

const greet = (name) => `Hello, ${name}!`; const add = (a, b) => a + b; const square = x => x * x;
📘 ការពន្យល់៖: Arrow function ខ្លីជាង និង មិនមាន this ផ្ទាល់ខ្លួន។ បើ body មានតែ return statement អាចសរសេរខ្លីបាន។

5.3 Default Parameters

function greet(name = "Guest") { return `Hello, ${name}!`; } greet(); // Hello, Guest! greet("Dara"); // Hello, Dara!

5.4 Closures

function counter() { let count = 0; return () => ++count; } const next = counter(); next(); // 1 next(); // 2
📘 ការពន្យល់៖: Closure គឺ function ដែលចងចាំ variable ពី scope ខាងក្រៅ ទោះបី function នោះត្រូវបានហៅនៅកន្លែងផ្សេងក៏ដោយ។

6. Arrays & Objects

6.1 Arrays

const nums = [1, 2, 3]; nums[0]; // 1 nums.length; // 3 nums.push(4); // បន្ថែម nums.pop(); // ដកចេញ

6.2 Array Methods

// map — បំប្លែងគ្រប់ element [1, 2, 3].map(n => n * 2); // [2, 4, 6] // filter — ជម្រើស element [1, 2, 3, 4].filter(n => n > 2); // [3, 4] // reduce — បូកសរុប [1, 2, 3].reduce((sum, n) => sum + n, 0); // 6 // find, some, every nums.find(n => n > 2); // 3 nums.some(n => n > 5); // false nums.every(n => n > 0); // true

6.3 Objects

const user = { name: "Dara", age: 20, greet() { return `Hi, I'm ${this.name}`; } }; user.name; // "Dara" user["age"]; // 20 user.greet(); // "Hi, I'm Dara"

6.4 Destructuring

// Object const { name, age } = user; // Array const [first, second] = [1, 2]; // Default values const { city = "Phnom Penh" } = user;

7. DOM Manipulation

7.1 Selecting Elements

document.getElementById("app"); document.querySelector(".btn"); document.querySelectorAll("li");

7.2 Modifying

el.textContent = "New text"; el.innerHTML = "<b>Bold</b>"; el.style.color = "red"; el.classList.add("active"); el.classList.remove("active"); el.classList.toggle("active");

7.3 Events

const btn = document.querySelector("#btn"); btn.addEventListener("click", (e) => { console.log("Clicked!", e.target); }); // Common events // click, submit, input, change, keydown, mouseover

7.4 Creating Elements

const li = document.createElement("li"); li.textContent = "New item"; document.querySelector("ul").appendChild(li); // Modern way container.append(li);

8. ES6+ Features

8.1 Spread / Rest

// Spread — ពង្រាយ const arr = [...[1, 2], 3, 4]; // [1, 2, 3, 4] const user = { ...{ name: "Dara" }, age: 20 }; // Rest — ប្រមូល function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }

8.2 Modules

// math.js export const PI = 3.14; export function add(a, b) { return a + b; } // app.js import { PI, add } from "./math.js";

8.3 Classes

class Student { constructor(name) { this.name = name; } greet() { return `Hi, I'm ${this.name}`; } } class Graduate extends Student { constructor(name, degree) { super(name); this.degree = degree; } }

8.4 Promises

const promise = new Promise((resolve, reject) => { setTimeout(() => resolve("Done!"), 1000); }); promise .then(result => console.log(result)) .catch(err => console.error(err));

9. Async / Await

9.1 Async Basics

async function fetchData() { return "Data"; } fetchData().then(data => console.log(data));

9.2 Fetch API

async function getUsers() { const response = await fetch("https://api.example.com/users"); const data = await response.json(); return data; }

9.3 Error Handling

async function getUsers() { try { const res = await fetch("url"); if (!res.ok) throw new Error("HTTP error"); return await res.json(); } catch (err) { console.error("Failed:", err); } }
📘 ការពន្យល់៖: async/await ធ្វើឲ្យកូដ asynchronous មើលទៅដូច synchronous។ ល្អសម្រាប់ API calls និង I/O operations។

10. Advanced Concepts

10.1 Higher-Order Functions

function multiplyBy(factor) { return (n) => n * factor; } const double = multiplyBy(2); double(5); // 10

10.2 this Keyword

const obj = { name: "Dara", greet() { console.log(this.name); } }; obj.greet(); // "Dara"

10.3 localStorage

localStorage.setItem("user", "Dara"); localStorage.getItem("user"); // "Dara" localStorage.removeItem("user"); localStorage.clear();

10.4 JSON

const user = { name: "Dara", age: 20 }; // Object → JSON string const json = JSON.stringify(user); // JSON string → Object const obj = JSON.parse(json);

11. Error Handling

11.1 try / catch

try { riskyOperation(); } catch (error) { console.error(error.message); } finally { console.log("Always runs"); }

11.2 throw

function divide(a, b) { if (b === 0) { throw new Error("Cannot divide by zero"); } return a / b; }

11.3 Debugging

console.log(); // បង្ហាញតម្លៃ console.table(); // តារាង console.time(); // ចាប់ផ្តើមកត់ពេល console.timeEnd(); // បញ្ចប់កត់ពេល debugger; // បញ្ឈប់នៅចំណុចនេះ

12. Regular Expressions

12.1 Basics

const regex = /[a-z]+/; const regex2 = new RegExp("[a-z]+", "g"); // Common patterns // \d — លេខ // \w — អក្សរ ឬ លេខ // \s — ចន្លោះ // . — តួអក្សរណាមួយ // * — 0 ឬច្រើន // + — 1 ឬច្រើន

12.2 Methods

const str = "Hello 123 World 456"; str.match(/\d+/g); // ["123", "456"] str.replace(/\d+/g, "#"); // "Hello # World #" str.test(/\d+/); // true

13. Modern JS (ES2020+)

13.1 Optional Chaining

const user = { name: "Dara" }; user?.name; // "Dara" user?.address?.city; // undefined (មិន error)

13.2 Nullish Coalescing

const name = null; const display = name ?? "Guest"; // "Guest" // ?? ផ្ទុយពី || 0 || "default" // "default" 0 ?? "default" // 0

13.3 BigInt

const big = 9007199254740991n; const bigger = big + 1n;

14. Best Practices

  • ប្រើ const ជាលំនាំដើម, let តែនៅពេលចាំបាច់
  • ប្រើ === ជំនួស ==
  • ប្រើ arrow functions សម្រាប់ callbacks
  • ប្រើ async/await ជំនួស promise chains
  • ប្រើ try/catch ជាមួយ async
  • ប្រើ destructuring និង spread
  • រក្សា functions តូច និងធ្វើរឿងតែមួយ
  • សរសេរ comments តែនៅពេលចាំបាច់
📘 ការពន្យល់៖: JavaScript មាន flexibility ខ្ពស់ — អាចសរសេរបានច្រើនរបៀប។ ការអនុវត្តតាម best practices នឹងជួយឲ្យកូដអានងាយ ថែទាំងាយ និងមាន bug តិច។
