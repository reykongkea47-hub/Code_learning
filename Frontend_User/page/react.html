1. React Introduction - ការណែនាំ React

1.1 អ្វីជា React?

React គឺជា JavaScript Library ដែលបង្កើតឡើងដោយ Facebook ក្នុងឆ្នាំ 2013 សម្រាប់បង្កើត UI។

📘 ការពន្យល់៖ React ជួយបង្កើត Single Page Application (SPA) ដែលផ្លាស់ប្តូរខ្លឹមសារដោយមិនចាំបាច់ reload ទំព័រ។ វាប្រើ Component ជាដុំៗ និង Virtual DOM សម្រាប់ performance ខ្ពស់។ ប្រើដោយ៖
  • Facebook, Instagram
  • Netflix, Airbnb
  • YouTube, WhatsApp Web

1.2 ការដំឡើង

  • Node.js — ត្រូវដំឡើងមុន
  • Vite — លឿនបំផុត (recommended)
  • Create React App — ចាស់បន្តិច
  • Next.js — framework ពេញលេញ
# បង្កើត project ថ្មីជាមួយ Vite npm create vite@latest my-app -- --template react cd my-app npm install npm run dev

1.3 App ដំបូង

// App.jsx function App() { return ( <div> <h1>Hello, React!</h1> </div> ); } export default App;

1.4 Folder Structure

my-app/ ├── src/ │ ├── App.jsx │ ├── main.jsx │ ├── components/ │ └── assets/ ├── public/ ├── package.json └── vite.config.js
📘 ការពន្យល់៖: main.jsx ជាចំណុចចាប់ផ្តើមដែល render App។ អ្នកអាចបង្កើត components ថ្មីៗនៅក្នុង folder components។

2. JSX

2.1 JSX Basics

const element = <h1>Hello World</h1>;
📘 ការពន្យល់៖: JSX (JavaScript XML) អនុញ្ញាតឲ្យសរសេរ HTML នៅក្នុង JavaScript។ វាមិនមែន HTML ពិតទេ ប៉ុន្តែ React បំប្លែងទៅ React.createElement()។

2.2 Expressions

const name = "Dara"; const greeting = <h1>Hello, {name}!</h1>; // ក៏អាចប្រើ expression <p>{2 + 3}</p> // 5

2.3 Attributes

<img src="logo.png" alt="Logo" /> <div className="box">...</div>
📘 ការពន្យល់៖: ក្នុង JSX ប្រើ className ជំនួស class, htmlFor ជំនួស for។ ប្រើ {} សម្រាប់បញ្ចូល JavaScript expression។

2.4 Fragments

return ( <> <h1>Title</h1> <p>Text</p> </> );
📘 ការពន្យល់៖: Fragment (<>...</>) អនុញ្ញាតឲ្យ return ច្រើន elements ដោយមិនចាំបាច់ដាក់ <div> បន្ថែម។

3. Components

3.1 Function Components

function Welcome() { return <h1>Welcome!</h1>; }

3.2 Class Components

import { Component } from 'react'; class Welcome extends Component { render() { return <h1>Welcome!</h1>; } }
📘 ការពន្យល់៖: បច្ចុប្បន្ន ប្រើ Function Components ជាមួយ Hooks ជាធម្មតា។ Class Components គឺជារបៀបចាស់។

3.3 Nested Components

function Header() { return <h1>Header</h1>; } function App() { return ( <div> <Header /> <p>Content</p> </div> ); }

3.4 Export / Import

// Header.jsx export default function Header() { return <h1>Header</h1>; } // App.jsx import Header from './Header';

4. Props

4.1 Passing Props

function Greeting(props) { return <h1>Hello, {props.name}!</h1>; } // ប្រើ <Greeting name="Dara" />

4.2 Destructuring

function Greeting({ name, age }) { return <h1>Hello, {name} ({age})</h1>; }

4.3 children

function Card({ children }) { return <div className="card">{children}</div>; } <Card> <p>Hello!</p> </Card>

4.4 Default Props

function Greeting({ name = "Guest" }) { return <h1>Hello, {name}</h1>; }
📘 ការពន្យល់៖: Props ជាទិន្នន័យដែលបញ្ជូនពី parent ទៅ child component។ វាជា read-only — child មិនអាចកែបានទេ។

5. State (useState)

5.1 useState Basics

import { useState } from 'react'; function Counter() { const [count, setCount] = useState(0); return ( <div> <p>Count: {count}</p> <button onClick={() => setCount(count + 1)}> +1 </button> </div> ); }
📘 ការពន្យល់៖: useState() return array 2 element៖ តម្លៃបច្ចុប្បន្ន និង function សម្រាប់ update។ នៅពេល state ផ្លាស់ប្តូរ React នឹង re-render component ដោយស្វ័យប្រវត្តិ។

5.2 Updating State

// ប្រើ function form (ល្អបំផុត) setCount(prev => prev + 1);

5.3 Object State

const [user, setUser] = useState({ name: "Dara", age: 20 }); // ត្រូវ copy object មុន setUser({ ...user, age: 21 });

5.4 Array State

const [items, setItems] = useState(["a", "b"]); // បន្ថែម setItems([...items, "c"]); // លុប setItems(items.filter(i => i !== "a"));
📘 ការពន្យល់៖: កុំកែ state ផ្ទាល់! ត្រូវបង្កើត copy ថ្មី (spread operator ...)។ វិធីនេះធានាថា React ដឹងពីការផ្លាស់ប្តូរ។

6. Event Handling

6.1 onClick

function Button() { function handleClick() { alert("Clicked!"); } return <button onClick={handleClick}>Click</button>; }

6.2 Input Events

function Input() { function handleChange(e) { console.log(e.target.value); } return <input onChange={handleChange} />; }

6.3 Form Events

function Form() { function handleSubmit(e) { e.preventDefault(); // បញ្ឈប់ reload alert("Submitted!"); } return ( <form onSubmit={handleSubmit}> <button>Submit</button> </form> ); }
📘 ការពន្យល់៖: Event ក្នុង React ជា camelCase (onClick មិនមែន onclick)។ បញ្ជូន function មិនមែន string។ e.preventDefault() ការពារ default behavior។

7. Conditional Rendering

7.1 if / else

function Greeting({ isLoggedIn }) { if (isLoggedIn) { return <h1>Welcome back!</h1>; } return <h1>Please log in.</h1>; }

7.2 Ternary

return ( <div> {isLoggedIn ? <h1>Welcome!</h1> : <h1>Log in</h1>} </div> );

7.3 Logical AND

{isAdmin && <button>Delete</button>}
📘 ការពន្យល់៖: && បង្ហាញធាតុតែនៅពេល condition ពិត។ ឧទាហរណ៍ isAdmin && <button /> បង្ហាញប៊ូតុងតែនៅពេល user ជា admin។

8. Lists & Keys

8.1 Rendering Lists

const fruits = ["Apple", "Banana", "Cherry"]; return ( <ul> {fruits.map((fruit, i) => <li key={i}>{fruit}</li>)} </ul> );

8.2 Keys

// ល្អបំផុតប្រើ id ជា key {users.map(user => ( <div key={user.id}>{user.name}</div> ))}
📘 ការពន្យល់៖: key ជួយ React ដឹងថា element ណាផ្លាស់ប្តូរ។ ត្រូវប្រើ unique និង stable — ល្អបំផុតគឺ database id។ កុំប្រើ index បើ list អាចផ្លាស់ប្តូរលំដាប់។

8.3 Filter List

const adults = users.filter(u => u.age >= 18);

9. useEffect

9.1 Basics

import { useEffect, useState } from 'react'; function Timer() { const [count, setCount] = useState(0); useEffect(() => { console.log("Count changed: " + count); }, [count]); return <button onClick={() => setCount(count + 1)}>{count}</button>; }
📘 ការពន្យល់៖: useEffect ដំណើរការ side effects — ដូចជា fetch data, subscribe, ឬកែ DOM។ វាដំណើរការបន្ទាប់ពី render។

9.2 Dependencies

useEffect(() => { ... }, []); // ដំណើរការម្តង useEffect(() => { ... }, [count]); // ពេល count ផ្លាស់ប្តូរ useEffect(() => { ... }); // រាល់ render

9.3 Fetch API

useEffect(() => { fetch("https://api.example.com/users") .then(res => res.json()) .then(data => setUsers(data)); }, []);

9.4 Cleanup

useEffect(() => { const timer = setInterval(() => {}, 1000); return () => clearInterval(timer); // cleanup }, []);
📘 ការពន្យល់៖: Cleanup function ជួយបញ្ឈប់ subscriptions, timers ជាដើម នៅពេល component ត្រូវ unmount។ ជួយការពារ memory leak។

13. Custom Hooks

13.1 Creating Hooks

import { useState } from 'react'; function useCounter(initial = 0) { const [count, setCount] = useState(initial); const increment = () => setCount(c => c + 1); const decrement = () => setCount(c => c - 1); return { count, increment, decrement }; }

13.2 useFetch Example

function useFetch(url) { const [data, setData] = useState(null); const [loading, setLoading] = useState(true); useEffect(() => { fetch(url) .then(res => res.json()) .then(d => { setData(d); setLoading(false); }); }, [url]); return { data, loading }; }
📘 ការពន្យល់៖: Custom Hook គឺ function ដែលចាប់ផ្តើមដោយ use និងអាចប្រើ Hooks ផ្សេងទៀត។ វាជួយកូដឡើងវិញ និងបំបែក logic។

15. React Project

សាកល្បងបង្កើត Todo List តូចមួយជាមួយ React៖

import { useState } from 'react'; function TodoApp() { const [todos, setTodos] = useState([]); const [input, setInput] = useState(""); function addTodo(e) { e.preventDefault(); if (!input) return; setTodos([...todos, { id: Date.now(), text: input }]); setInput(""); } function removeTodo(id) { setTodos(todos.filter(t => t.id !== id)); } return ( <div> <h1>Todo List</h1> <form onSubmit={addTodo}> <input value={input} onChange={(e) => setInput(e.target.value)} placeholder="បន្ថែម..." /> <button>Add</button> </form> <ul> {todos.map(t => ( <li key={t.id}> {t.text} <button onClick={() => removeTodo(t.id)}>×</button> </li> ))} </ul> </div> ); } export default TodoApp;
📘 ការពន្យល់៖: គម្រោងនេះប្រើ useState, form handling, list rendering និង key។ សាកល្បងបន្ថែម៖ edit, filter, ឬ localStorage។
គន្លឹះ៖: សាកល្បងគម្រោងតូចៗ — Todo List, Weather App, Shopping Cart — វានឹងជួយអ្នកយល់ React លឿនជាងអានទ្រឹស្តី។
