1. Java Introduction - ការណែនាំ Java

1.1 អ្វីជា Java?

Java គឺជាភាសា Object-Oriented ដែលបង្កើតឡើងដោយ James Gosling នៅ Sun Microsystems ក្នុងឆ្នាំ 1995។

📘 ការពន្យល់៖ Java មានគោលការណ៍ "Write Once, Run Anywhere" (សរសេរម្តង រត់បានគ្រប់ទីកន្លែង)។ កូដ Java ត្រូវបាន compile ទៅជា bytecode ដែលអាចរត់លើគ្រប់ platform ដែលមាន JVM។ ប្រើសម្រាប់៖
  • Android Apps — កម្មវិធីទូរស័ព្ទ
  • Enterprise Systems — ប្រព័ន្ធសហគ្រាស
  • Web Backend — Spring Boot
  • Big Data — Hadoop, Spark

1.2 JVM / JRE / JDK

  • JVM — Java Virtual Machine (ដំណើរការ bytecode)
  • JRE — Java Runtime Environment (JVM + libraries)
  • JDK — Java Development Kit (JRE + tools សម្រាប់អភិវឌ្ឍន៍)
📘 ការពន្យល់៖: បើអ្នកចង់ សរសេរកូដ Java ត្រូវការ JDK។ បើគ្រាន់តែ រត់ កម្មវិធី Java ត្រូវការ JRE។ JVM គឺជាកម្មវិធីដែលរត់ bytecode។

1.3 ការដំឡើង

  • ទាញយក JDK ពី oracle.com ឬ adoptium.net
  • IDE: IntelliJ IDEA, Eclipse, VS Code
  • ពិនិត្យដោយ: java -version

1.4 កម្មវិធីដំបូង

public class Hello { public static void main(String[] args) { System.out.println("Hello, Java!"); } }
📘 ការពន្យល់លម្អិត៖:
  • public class Hello — ឈ្មោះ class ត្រូវតែដូចឈ្មោះ file (Hello.java)
  • public static void main(String[] args) — ចំណុចចាប់ផ្តើមរបស់កម្មវិធី
  • System.out.println() — បង្ហាញអត្ថបទ និងបន្ទាត់ថ្មី

2. Variables & Data Types

2.1 Variables

int age = 20; double price = 9.99; char grade = 'A'; boolean isActive = true; String name = "Dara";
📘 ការពន្យល់៖: Java ជាភាសា statically-typed — ត្រូវប្រកាស type ជានិច្ច។ មិនដូច JavaScript/PHP ដែល type ប្រែប្រួលបាន។

2.2 Primitive Types

  • byte — 1 byte (-128 ដល់ 127)
  • short — 2 bytes
  • int — 4 bytes (ចំនួនគត់ធម្មតា)
  • long — 8 bytes
  • float — 4 bytes
  • double — 8 bytes (ទសភាគធម្មតា)
  • char — 2 bytes (អក្សរ)
  • boolean — true / false

2.3 Type Casting

// Widening (auto) int x = 10; double y = x; // Narrowing (manual) double d = 9.99; int i = (int) d; // 9

2.4 Constants

final double PI = 3.14159;
📘 ការពន្យល់៖: final ធ្វើឲ្យ variable មិនអាចផ្លាស់ប្តូរតម្លៃបាន។ ប្រើ static final សម្រាប់ constants កម្រិត class។

3. Operators

3.1 Arithmetic

int sum = 5 + 3; // 8 int mod = 10 % 3; // 1 double pow = Math.pow(2, 3); // 8.0

3.2 Comparison

== != > < >= <=

3.3 Logical

&& // AND || // OR ! // NOT

3.4 Ternary

String result = (age >= 18) ? "Adult" : "Minor";
📘 ការពន្យល់៖: Ternary គឺជាមធ្យោបាយខ្លីសម្រាប់ if-else ។ ទម្រង់: condition ? valueIfTrue : valueIfFalse។

4. Control Flow

4.1 if / else

if (age >= 18) { System.out.println("Adult"); } else if (age >= 13) { System.out.println("Teen"); } else { System.out.println("Child"); }

4.2 switch

switch (day) { case 1: System.out.println("Mon"); break; case 2: System.out.println("Tue"); break; default: System.out.println("?"); }

4.3 Loops

for (int i = 0; i < 5; i++) { System.out.print(i + " "); } int j = 0; while (j < 5) { j++; } do { j++; } while (j < 10);

4.4 Enhanced For

int[] nums = {1, 2, 3}; for (int n : nums) { System.out.println(n); }
📘 ការពន្យល់៖: Enhanced for (for-each) ប្រើសម្រាប់ loop លើ array ឬ collection ដោយមិនចាំបាច់ប្រើ index។ ខ្លី និងសុវត្ថិភាពជាង។

5. Methods

5.1 Basics

public static void greet() { System.out.println("Hello!"); }

5.2 Params & Return

public static int add(int a, int b) { return a + b; }

5.3 Overloading

public static int add(int a, int b) { return a + b; } public static double add(double a, double b) { return a + b; }

5.4 Recursion

public static int factorial(int n) { if (n <= 1) return 1; return n * factorial(n - 1); }
📘 ការពន្យល់៖: Method ជាកូដដែលអាចហៅឡើងវិញ។ static មានន័យថាមិនចាំបាច់បង្កើត object។ Overloading អនុញ្ញាតឈ្មោះដូចគ្នា ប៉ុន្តែ parameters ខុសគ្នា។

6. Arrays & Strings

6.1 Arrays

int[] nums = {1, 2, 3}; System.out.println(nums[0]); // 1 System.out.println(nums.length); // 3

6.2 2D Arrays

int[][] matrix = {{1,2}, {3,4}}; System.out.println(matrix[1][0]); // 3

6.3 Strings

String name = "Dara"; name.length(); // 4 name.toUpperCase(); // DARA name.charAt(0); // D name.substring(0, 2); // Da name.equals("Dara"); // true

6.4 StringBuilder

StringBuilder sb = new StringBuilder(); sb.append("Hello"); sb.append(" World"); System.out.println(sb.toString());
📘 ការពន្យល់៖: String ក្នុង Java គឺ immutable (មិនអាចផ្លាស់ប្តូរ)។ បើកែ string ច្រើនដង គួរប្រើ StringBuilder ដែលលឿនជាង។

7. OOP - Classes

7.1 Classes & Objects

class Student { String name; int age; void greet() { System.out.println("Hi, I'm " + name); } } Student s1 = new Student(); s1.name = "Dara"; s1.greet();

7.2 Constructors

class Student { String name; Student(String n) { this.name = n; } } Student s = new Student("Dara");

7.3 Encapsulation

class Bank { private double balance; public void deposit(double amt) { if (amt > 0) balance += amt; } public double getBalance() { return balance; } }

7.4 static

class Counter { static int count = 0; Counter() { count++; } }
📘 ការពន្យល់៖: private លាក់ data ពីខាងក្រៅ។ this ជា reference ទៅ object បច្ចុប្បន្ន។ static មានន័យថាជាកម្មសិទ្ធិរបស់ class មិនមែន object។

8. Inheritance & Polymorphism

8.1 Inheritance

class Animal { void eat() { System.out.println("Eating"); } } class Dog extends Animal { void bark() { System.out.println("Woof"); } }

8.2 super

class Dog extends Animal { Dog() { super(); // ហៅ constructor របស់ parent } }

8.3 Overriding

@Override void sound() { System.out.println("Woof woof"); }

8.4 Abstract & Interface

abstract class Shape { abstract void draw(); } interface Flyable { void fly(); }
📘 ការពន្យល់៖: Inheritance ឲ្យ class កូនទទួលមរតកពី class មេ។ Abstract class មិនអាចបង្កើត object ផ្ទាល់បាន។ Interface ជាកិច្ចសន្យាដែល class ត្រូវអនុវត្ត។

9. Collections

9.1 List (ArrayList)

import java.util.ArrayList; ArrayList<String> names = new ArrayList<>(); names.add("Dara"); names.add("Sok"); names.get(0); // Dara names.size(); // 2

9.2 Set (HashSet)

import java.util.HashSet; HashSet<Integer> nums = new HashSet<>(); nums.add(1); nums.add(1); // មិនបន្ថែមទេ (duplicate)

9.3 Map (HashMap)

import java.util.HashMap; HashMap<String, Integer> ages = new HashMap<>(); ages.put("Dara", 20); ages.get("Dara"); // 20

9.4 Iterator

Iterator<String> it = names.iterator(); while (it.hasNext()) { System.out.println(it.next()); }
📘 ការពន្យល់៖: Collections ជាប្រព័ន្ធផ្ទុកទិន្នន័យដែលបត់បែនបាន។ List រក្សាលំដាប់, Set មិនឲ្យ duplicate, Map ផ្ទុក key-value។

10. Generics

10.1 Generic Classes

class Box<T> { private T value; public void set(T value) { this.value = value; } public T get() { return value; } } Box<String> b = new Box<>(); b.set("Hello");

10.2 Generic Methods

public static <T> void print(T item) { System.out.println(item); }

10.3 Wildcards

public void printList(List<?> list) { for (Object o : list) System.out.println(o); }
📘 ការពន្យល់៖: Generics អនុញ្ញាតឲ្យសរសេរកូដដែលដំណើរការជាមួយ type ណាមួយ ដោយរក្សា type safety។ ឧទាហរណ៍ List<String> មានន័យថា list នៃ String។

11. Exception Handling

11.1 try / catch

try { int result = 10 / 0; } catch (ArithmeticException e) { System.out.println("Error: " + e.getMessage()); } finally { System.out.println("Always runs"); }

11.2 throws

public void readFile() throws IOException { // ... }

11.3 Custom Exception

class MyException extends Exception { MyException(String msg) { super(msg); } }
📘 ការពន្យល់៖: Java ប្រើ try-catch-finally សម្រាប់ចាប់ exception។ finally តែងតែដំណើរការ (ទោះមាន error ឬអត់)។ ប្រើសម្រាប់បិទ file/connection។

12. File I/O

12.1 Read File

import java.io.File; import java.util.Scanner; File file = new File("data.txt"); Scanner sc = new Scanner(file); while (sc.hasNextLine()) { System.out.println(sc.nextLine()); } sc.close();

12.2 Write File

import java.io.FileWriter; import java.io.IOException; try { FileWriter w = new FileWriter("data.txt"); w.write("Hello File!"); w.close(); } catch (IOException e) { e.printStackTrace(); }
📘 ការពន្យល់៖: Java ប្រើ Scanner សម្រាប់អាន និង FileWriter សម្រាប់សរសេរ file។ ត្រូវបិទ resource ជានិច្ច (close()) ដើម្បីការពារ memory leak។

13. Multithreading

13.1 Thread Basics

class MyThread extends Thread { public void run() { System.out.println("Running in thread"); } } MyThread t = new MyThread(); t.start();

13.2 Runnable

Runnable r = () -> System.out.println("Running"); Thread t = new Thread(r); t.start();

13.3 Synchronization

synchronized void increment() { count++; }
📘 ការពន្យល់៖: Multithreading អនុញ្ញាតឲ្យកម្មវិធីធ្វើការច្រើនក្នុងពេលតែមួយ។ synchronized ការពារការប៉ះទង្គិចគ្នានៃ threads។

14. Modern Java (8+)

14.1 Lambda

List<Integer> nums = Arrays.asList(1, 2, 3); nums.forEach(n -> System.out.println(n));

14.2 Stream API

List<String> names = Arrays.asList("Dara", "Sok", "Anna"); List<String> result = names.stream() .filter(n -> n.startsWith("D")) .map(String::toUpperCase) .collect(Collectors.toList());

14.3 Optional

Optional<String> opt = Optional.of("Hello"); opt.ifPresent(System.out::println);
📘 ការពន្យល់៖: Java 8 បន្ថែម Lambda, Stream API និង Optional ដែលធ្វើឲ្យកូដខ្លី និងមាន performance ខ្ពស់។ Optional ជួយជៀសវាង NullPointerException។

15. Java Project

សាកល្បងបង្កើតកម្មវិធី Student Manager តូចមួយ៖

import java.util.ArrayList; class Student { String name; int age; Student(String name, int age) { this.name = name; this.age = age; } public String toString() { return name + " (" + age + ")"; } } public class StudentManager { public static void main(String[] args) { ArrayList<Student> students = new ArrayList<>(); students.add(new Student("Dara", 20)); students.add(new Student("Sok", 22)); for (Student s : students) { System.out.println(s); } } }
📘 ការពន្យល់៖: គម្រោងនេះប្រើ class, constructor, toString(), ArrayList និង enhanced for។ សាកល្បងបន្ថែមមុខងារ៖ លុប, កែ, ឬរកមើល។
គន្លឹះ៖ សាកល្បងគម្រោងតូចៗ ដូចជា To-do List, Calculator, Bank System។ វានឹងជួយអ្នកយល់ Java លឿនជាងអានទ្រឹស្តី។
