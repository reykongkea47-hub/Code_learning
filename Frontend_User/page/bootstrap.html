1. Bootstrap Introduction - ការណែនាំ Bootstrap

1.1 អ្វីជា Bootstrap?

Bootstrap គឺជា CSS Framework ដ៏ពេញនិយមបំផុត ដែលបង្កើតឡើងដោយ Twitter ក្នុងឆ្នាំ 2011។

📘 ការពន្យល់៖: Bootstrap ផ្តល់ជូន class ដែលរួចរាល់សម្រាប់បង្កើត UI លឿន។ វាមាន grid system ដ៏មានឥទ្ធិឫទ្ធិ, components ច្រើន, និង JavaScript plugins។ ប្រើសម្រាប់៖
  • Admin Dashboards — ផ្ទាំងគ្រប់គ្រង
  • Landing Pages — ទំព័រផ្សព្វផ្សាយ
  • E-commerce — គេហទំព័រលក់ទំនិញ
  • Blog Templates — ទំព័រប្លុក

1.2 ហេតុអ្វីប្រើ Bootstrap?

  • រហ័ស — មាន components រួចរាល់
  • Responsive — ដំណើរការលើគ្រប់អេក្រង់
  • Consistent — Design ស្មើគ្នា
  • Browser Support — គាំទ្រគ្រប់ browser
  • Community — សហគមន៍ធំ

1.3 ការដំឡើង

វិធី ១៖ ប្រើ CDN (ងាយស្រួលបំផុត)

<!-- CSS --> <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet"> <!-- JS --> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>

វិធី ២៖ ដំឡើងក្នុងគម្រោង

npm install bootstrap

1.4 ទំព័រដំបូង

<!DOCTYPE html> <html lang="km"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet"> <title>Bootstrap Page</title> </head> <body> <div class="container"> <h1 class="text-primary">Hello, Bootstrap!</h1> <button class="btn btn-primary">Click me</button> </div> </body> </html>

2. Container & Grid System

2.1 Container

  • .container — ទទឹងថេរ (responsive)
  • .container-fluid — ពេញអេក្រង់ (100%)
  • .container-sm / .container-lg — breakpoint ជាក់លាក់

2.2 Grid Basics

Bootstrap grid ប្រើ 12 columns ជាមូលដ្ឋាន។

<div class="container"> <div class="row"> <div class="col-6">ពាក់កណ្តាល (6/12)</div> <div class="col-6">ពាក់កណ្តាល (6/12)</div> </div> <div class="row"> <div class="col-4">1/3</div> <div class="col-4">1/3</div> <div class="col-4">1/3</div> </div> </div>

2.3 Breakpoints

Classទំហំឧទាហរណ៍
col-*< 576pxExtra small
col-sm-*≥ 576pxSmall
col-md-*≥ 768pxMedium (Tablet)
col-lg-*≥ 992pxLarge (Laptop)
col-xl-*≥ 1200pxExtra large
col-xxl-*≥ 1400pxXXL
<!-- ១ ជួរលើទូរស័ព្ទ ២ ជួរលើ tablet ៤ ជួរលើ desktop --> <div class="row"> <div class="col-12 col-md-6 col-lg-3">ប្រអប់</div> </div>

2.4 Offset & Order

<!-- Offset --> <div class="col-4 offset-4">កណ្តាល</div> <!-- Order --> <div class="col order-2">ទី ២</div> <div class="col order-1">ទី ១</div>

10. Utilities

10.1 Spacing

Format: {property}{sides}-{size}

  • Property: m (margin), p (padding)
  • Sides: t (top), b (bottom), s (start), e (end), x (left+right), y (top+bottom), blank (all)
  • Size: 0, 1, 2, 3, 4, 5 (0 = 0, 5 = 3rem)
<div class="mt-3 mb-4 px-2 py-1"></div>

10.2 Colors

<!-- Text color --> <p class="text-primary">Primary</p> <p class="text-success">Success</p> <p class="text-danger">Danger</p> <p class="text-muted">Muted</p> <!-- Background --> <div class="bg-primary text-white">Primary BG</div>

10.3 Display & Flex

<!-- Display --> <div class="d-none d-md-block"></div> <span class="d-inline"></span> <!-- Flex --> <div class="d-flex justify-content-between align-items-center"> <div>Left</div> <div>Right</div> </div>

10.4 Positioning

14. Best Practices

  • ប្រើ container ជាប្រអប់ខាងក្រៅ
  • ប្រើ grid classes ជំនួស custom CSS
  • ប្រើ utility classes សម្រាប់ spacing
  • រក្សា HTML semantic និង accessible
  • ប្រើ row-cols-* សម្រាប់ responsive cards
  • មិន override Bootstrap ច្រើនពេក
  • ប្រើ JS bundle សម្រាប់ plugins
  • Test លើគ្រប់ breakpoint
