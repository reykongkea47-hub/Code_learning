1. PHP Introduction - ការណែនាំ PHP

1.1 អ្វីជា PHP?

PHP (PHP: Hypertext Preprocessor) គឺជាភាសា server-side scripting ដែលប្រើសម្រាប់បង្កើតគេហទំព័រឌីណាមិក។

📘 ការពន្យល់៖ PHP ដំណើរការនៅលើ server (ម៉ាស៊ីនបម្រើ) មុនពេលផ្ញើ HTML ទៅ browser។ វាអាចភ្ជាប់ជាមួយ database ដើម្បីបង្កើតប្រព័ន្ធដូចជា៖
  • WordPress — ប្រព័ន្ធគ្រប់គ្រងមាតិកា
  • Facebook — ដំបូងបង្កើតដោយ PHP
  • Wikipedia — សព្វវចនាធិប្បាយ
  • Laravel — PHP Framework ពេញនិយម

1.2 ការដំឡើង

  • XAMPP — Windows, Mac, Linux (ងាយស្រួលបំផុត)
  • MAMP — Mac / Windows
  • Laragon — Windows
  • PHP + MySQL ដំឡើងដោយផ្ទាល់
📘 ការពន្យល់៖: XAMPP គឺជាកញ្ចប់ដែលរួមមាន Apache (Web Server), PHP, និង MySQL។ ដំឡើងរួច អ្នកអាចដាក់ file PHP ក្នុង folder htdocs ហើយបើកតាម http://localhost/។

1.3 Script ដំបូង

<?php echo "Hello, PHP!"; ?>
📘 ការពន្យល់៖: កូដ PHP ត្រូវដាក់ក្នុង <?php ... ?>។ echo គឺជាមុខងារសម្រាប់បង្ហាញអត្ថបទ។

1.4 Syntax

<?php // Statement ត្រូវបញ្ចប់ដោយ ; echo "Line 1"; echo "Line 2"; ?>

2. Variables & Data Types

2.1 Variables

<?php $name = "Dara"; $age = 20; $price = 9.99; echo $name; ?>
📘 ការពន្យល់៖: Variable ក្នុង PHP ចាប់ផ្តើមដោយសញ្ញា $។ មិនចាំបាច់ប្រកាស type ទេ — PHP ស្គាល់ដោយស្វ័យប្រវត្តិ។

2.2 Data Types

  • String — "Hello"
  • Integer — 100
  • Float — 3.14
  • Boolean — true / false
  • Array — [1, 2, 3]
  • NULL — គ្មានតម្លៃ
  • Object — Instance នៃ class

2.3 Constants

<?php define("PI", 3.14159); echo PI; ?>
📘 ការពន្យល់៖: Constant មិនអាចផ្លាស់ប្តូរតម្លៃបានទេ។ ប្រើ define() ឬ const ។ មិនប្រើ $ ទេ។

2.4 Superglobals

  • $_GET — ទិន្នន័យពី URL
  • $_POST — ទិន្នន័យពី Form
  • $_SESSION — ទិន្នន័យ session
  • $_COOKIE — ទិន្នន័យ cookie
  • $_SERVER — ព័ត៌មាន server
📘 ការពន្យល់៖: Superglobals គឺ variables ដែលអាចចូលបានពីគ្រប់ទីកន្លែងក្នុងកូដ។ មានប្រយោជន៍សម្រាប់ទទួលទិន្នន័យពី user។

3. Operators

3.1 Arithmetic

<?php echo 5 + 3; // 8 echo 10 % 3; // 1 echo 2 ** 3; // 8 (power) ?>

3.2 Comparison

== // ស្មើ (មិនខ្វល់ type) === // ស្មើ (ខ្វល់ type) != // មិនស្មើ > < >= <=
📘 ការពន្យល់៖: == ប្រៀបធៀបតម្លៃតែប៉ុណ្ណោះ ខណៈ === ប្រៀបធៀបទាំងតម្លៃ និង type។ ឧទាហរណ៍ "5" == 5 គឺ true ប៉ុន្តែ "5" === 5 គឺ false។

3.3 Logical

&& // AND || // OR ! // NOT

3.4 String Operators

<?php $a = "Hello"; $b = " World"; echo $a . $b; // Hello World ?>
📘 ការពន្យល់៖: ក្នុង PHP ប្រើ . (dot) សម្រាប់ភ្ជាប់ string (មិនដូច JavaScript ដែលប្រើ +)។

4. Control Flow

4.1 if / else

<?php $age = 20; if ($age >= 18) { echo "Adult"; } elseif ($age >= 13) { echo "Teen"; } else { echo "Child"; } ?>

4.2 switch

<?php $day = 1; switch ($day) { case 1: echo "Monday"; break; case 2: echo "Tuesday"; break; default: echo "Unknown"; } ?>

4.3 Loops

<?php // for loop for ($i = 0; $i < 5; $i++) { echo $i . " "; } // while loop $j = 0; while ($j < 5) { echo $j; $j++; } ?>

4.4 foreach

<?php $colors = ["red", "green", "blue"]; foreach ($colors as $color) { echo $color . " "; } ?>
📘 ការពន្យល់៖: foreach គឺ loop ពិសេសសម្រាប់ array។ វាឆ្លងកាត់គ្រប់ element ដោយស្វ័យប្រវត្តិ ដោយមិនចាំបាច់ប្រើ index។

5. Functions

5.1 Basics

<?php function greet() { echo "Hello!"; } greet(); // ហៅ function ?>

5.2 Parameters

<?php function greet($name) { echo "Hello, " . $name; } greet("Dara"); ?>

5.3 Return

<?php function add($a, $b) { return $a + $b; } $sum = add(2, 3); echo $sum; // 5 ?>

5.4 Default Values

<?php function greet($name = "Guest") { echo "Hello, " . $name; } greet(); // Hello, Guest greet("Dara"); // Hello, Dara ?>
📘 ការពន្យល់៖: Function ជួយកូដឡើងវិញ។ Parameter អាចមាន default value ដែលប្រើនៅពេលអ្នកមិនបញ្ជូន argument។

6. Arrays

6.1 Indexed Arrays

<?php $fruits = ["Apple", "Banana", "Cherry"]; echo $fruits[0]; // Apple ?>

6.2 Associative

<?php $user = [ "name" => "Dara", "age" => 20 ]; echo $user["name"]; // Dara ?>

6.3 Multidimensional

<?php $users = [ ["name" => "Dara", "age" => 20], ["name" => "Sok", "age" => 25] ]; echo $users[0]["name"]; // Dara ?>

6.4 Array Functions

<?php count($arr); // ចំនួន element array_push($arr, 4); // បន្ថែម array_pop($arr); // ដកចេញ sort($arr); // តម្រៀប ?>

7. Strings

7.1 String Functions

<?php strlen("Hello"); // 5 strtoupper("hello"); // HELLO strtolower("HELLO"); // hello trim(" hi "); // "hi" substr("Hello", 0, 3); // "Hel" ?>

7.2 Concatenation

<?php $first = "Hello"; $last = "World"; echo $first . " " . $last; ?>

7.3 Replace

<?php echo str_replace("World", "Dara", "Hello World"); // Hello Dara ?>

8. Forms & Input

8.1 GET vs POST

  • GET — ទិន្នន័យបង្ហាញក្នុង URL (មិនសុវត្ថិភាព)
  • POST — ទិន្នន័យបញ្ជូនក្នុង body (សុវត្ថិភាពជាង)

8.2 Form Handling

<!-- form.html --> <form method="post" action="submit.php"> <input type="text" name="name"> <button type="submit">បញ្ជូន</button> </form> <!-- submit.php --> <?php if ($_SERVER["REQUEST_METHOD"] == "POST") { $name = $_POST["name"]; echo "Hello, " . htmlspecialchars($name); } ?>

8.3 Validation

<?php $email = $_POST["email"]; if (!filter_var($email, FILTER_VALIDATE_EMAIL)) { echo "Invalid email"; } ?>
📘 ការពន្យល់៖: ត្រូវ validate ទិន្នន័យពី user ជានិច្ច។ ប្រើ filter_var សម្រាប់ email, URL ជាដើម។ ប្រើ htmlspecialchars ដើម្បីការពារ XSS។

9. Sessions & Cookies

9.1 Sessions

<?php session_start(); $_SESSION["user"] = "Dara"; echo $_SESSION["user"]; ?>
📘 ការពន្យល់៖: Session ផ្ទុកទិន្នន័យនៅលើ server ហើយប្រើ session_id ដើម្បីចងចាំ user។ ត្រូវហៅ session_start() មុនប្រើ។ ល្អសម្រាប់ login។

9.2 Cookies

<?php setcookie("user", "Dara", time() + 86400); echo $_COOKIE["user"]; ?>
📘 ការពន្យល់៖: Cookie ផ្ទុកទិន្នន័យនៅលើ browser របស់ user។ កំណត់រយៈពេលផុតកំណត់ជា seconds (86400 = 1 ថ្ងៃ)។

10. File Handling

10.1 Read File

<?php $content = file_get_contents("data.txt"); echo $content; ?>

10.2 Write File

<?php file_put_contents("data.txt", "Hello!"); ?>

10.3 Upload

<?php if ($_FILES["file"]["error"] == 0) { move_uploaded_file( $_FILES["file"]["tmp_name"], "uploads/" . $_FILES["file"]["name"] ); } ?>
📘 ការពន្យល់៖: file_get_contents និង file_put_contents គឺវិធីងាយស្រួលបំផុតក្នុងការអាន/សរសេរ file។ សម្រាប់ upload ប្រើ $_FILES។

11. OOP in PHP

11.1 Classes & Objects

<?php class Student { public $name; public $age; public function greet() { return "Hi, I'm " . $this->name; } } $s1 = new Student(); $s1->name = "Dara"; echo $s1->greet(); ?>

11.2 Constructors

<?php class Student { public $name; public function __construct($name) { $this->name = $name; } } $s = new Student("Dara"); echo $s->name; ?>

11.3 Inheritance

<?php class Animal { public function eat() { echo "Eating"; } } class Dog extends Animal { public function bark() { echo "Woof"; } } $dog = new Dog(); $dog->eat(); // ទទួលពី Animal $dog->bark(); // របស់ Dog ?>
📘 ការពន្យល់៖: OOP ជួយកូដមានរចនាសម្ព័ន្ធ។ $this ជា reference ទៅ object បច្ចុប្បន្ន។ extends សម្រាប់ inheritance។

12. Database (MySQL)

12.1 Connect

<?php $conn = new mysqli("localhost", "root", "", "mydb"); if ($conn->connect_error) { die("Connection failed"); } ?>

12.2 Query

<?php $result = $conn->query("SELECT * FROM users"); while ($row = $result->fetch_assoc()) { echo $row["name"]; } ?>

12.3 Prepared Statements

<?php $stmt = $conn->prepare("SELECT * FROM users WHERE id = ?"); $stmt->bind_param("i", $id); $stmt->execute(); $result = $stmt->get_result(); ?>
📘 ការពន្យល់៖: Prepared Statements ការពារការ SQL Injection។ ប្រើ ? ជា placeholder ហើយ bind_param ភ្ជាប់តម្លៃពិត។ ត្រូវប្រើជានិច្ច។

13. Error Handling

13.1 try / catch

<?php try { throw new Exception("Something went wrong"); } catch (Exception $e) { echo "Error: " . $e->getMessage(); } ?>

13.2 throw

ប្រើ throw ដើម្បីបោះ exception នៅពេលមានបញ្ហា។

📘 ការពន្យល់៖: Exception ជួយចាប់កំហុសដោយមិនធ្វើឲ្យកម្មវិធីឈប់ភ្លាម។ ប្រើ try-catch សម្រាប់ដោះស្រាយដោយរលូន។

14. Security Best Practices

14.1 XSS Prevention

<?php echo htmlspecialchars($userInput, ENT_QUOTES, "UTF-8"); ?>

14.2 SQL Injection

ប្រើ Prepared Statements ជានិច្ច ដើម្បីការពារ SQL injection។

14.3 Password Hashing

<?php $hash = password_hash($password, PASSWORD_DEFAULT); if (password_verify($input, $hash)) { // ត្រឹមត្រូវ } ?>
📘 ការពន្យល់៖: កុំផ្ទុក password ជា plain text! ប្រើ password_hash និង password_verify។ ប្រើ htmlspecialchars ពេលបង្ហាញទិន្នន័យពី user ដើម្បីការពារ XSS។

15. PHP Project

សាកល្បងបង្កើតទំព័រ Contact Form ដែលទទួលទិន្នន័យ និងបង្ហាញវាត្រឡប់មកវិញ៖

<!-- contact.php --> <form method="post"> <input type="text" name="name" placeholder="ឈ្មោះ" required> <input type="email" name="email" placeholder="អ៊ីមែល" required> <textarea name="message" placeholder="សារ"></textarea> <button type="submit">ផ្ញើ</button> </form> <?php if ($_SERVER["REQUEST_METHOD"] == "POST") { $name = htmlspecialchars($_POST["name"]); $email = filter_var($_POST["email"], FILTER_VALIDATE_EMAIL); $message = htmlspecialchars($_POST["message"]); if ($name && $email && $message) { echo "<h3>សូមអរគុណ, $name!</h3>"; echo "<p>យើងនឹងទាក់ទងទៅ $email</p>"; } else { echo "សូមបំពេញព័ត៌មានឲ្យបានត្រឹមត្រូវ"; } } ?>
📘 ការពន្យល់៖: គម្រោងនេះប្រើ៖
  • Form ជាមួយ method="post"
  • Superglobal $_POST ទទួលទិន្នន័យ
  • htmlspecialchars ការពារ XSS
  • filter_var validate email
គន្លឹះ៖ សាកល្បងធ្វើគម្រោងតូចៗ ដូចជា To-do List, Login System, Blog។ វានឹងជួយអ្នកយល់ PHP លឿនជាងអានទ្រឹស្តី។
