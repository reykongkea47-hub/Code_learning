1. C# Introduction - ការណែនាំ C#

1.1 អ្វីជា C#?

C# (អានថា "C Sharp") គឺជាភាសាសរសេរកម្មវិធី object-oriented ដែលបង្កើតឡើងដោយ Microsoft ក្នុងឆ្នាំ 2000។

📘 ការពន្យល់៖ C# ដំណើរការលើ .NET Framework ឬ .NET Core (ឥឡូវហៅថា .NET 5+)។ វាជាភាសាដ៏ពេញនិយមសម្រាប់៖
  • Windows Apps — Desktop applications
  • Web Apps — ASP.NET Core
  • Game Development — Unity Engine
  • Mobile Apps — Xamarin / MAUI
  • Cloud Services — Azure

1.2 .NET Framework

  • .NET Framework — ជំនាន់ចាស់ (Windows only)
  • .NET Core — Cross-platform (Windows, Mac, Linux)
  • .NET 5/6/7/8 — ជំនាន់ថ្មីបំផុត (unified)
  • Mono — សម្រាប់ Unity / Mobile
📘 ការពន្យល់៖: .NET គឺជាប្រព័ន្ធដែលរួមមាន runtime (CLR) និង libraries។ C# code ត្រូវបាន compile ទៅជា IL (Intermediate Language) ហើយរត់លើ CLR។

1.3 ការដំឡើង

  • .NET SDK — ទាញយកពី dotnet.microsoft.com
  • Visual Studio — IDE ពេញលេញ (Windows/Mac)
  • VS Code — Editor ស្រាល + C# extension
  • Rider — JetBrains IDE
# ពិនិត្យការដំឡើង dotnet --version # បង្កើត project ថ្មី dotnet new console -n MyApp cd MyApp dotnet run

1.4 កម្មវិធីដំបូង

using System; namespace MyApp { class Program { static void Main(string[] args) { Console.WriteLine("Hello, C#!"); } } }
📘 ការពន្យល់លម្អិត៖:
  • using System; — import namespace
  • namespace — រៀបចំ code ជាក្រុម
  • class Program — កំណត់ class មួយ
  • static void Main() — ចំណុចចាប់ផ្តើម
  • Console.WriteLine() — បង្ហាញអត្ថបទ
គន្លឹះ៖ ក្នុង C# 10+ អ្នកអាចប្រើ top-level statements ដោយមិនចាំបាច់សរសេរ class៖ Console.WriteLine("Hello");

2. Variables & Data Types

2.1 Variables

int age = 20; double price = 9.99; char grade = 'A'; bool isActive = true; string name = "Dara";
📘 ការពន្យល់៖: C# ជាភាសា strongly-typed — ត្រូវប្រកាស type ជានិច្ច។ Variable ត្រូវតែ initialize មុនប្រើ (ខុសពី C++)។

2.2 Data Types

  • int — ចំនួនគត់ (4 bytes)
  • long — ចំនួនធំ (8 bytes)
  • float, double, decimal — ទសភាគ
  • bool — true / false
  • char — អក្សរ (2 bytes — Unicode)
  • string — អត្ថបទ
  • object — base type ទាំងអស់

2.3 var & dynamic

var x = 10; // int var name = "Dara"; // string dynamic y = 10; y = "Hello"; // អាចផ្លាស់ប្តូរ type បាន
📘 ការពន្យល់៖: var ឲ្យ compiler ស្គាល់ type ដោយស្វ័យប្រវត្តិ (មិនអាចផ្លាស់ប្តូរបាន)។ dynamic អាចផ្លាស់ប្តូរ type បាន ប៉ុន្តែមាន performance ទាបជាង។

2.4 Constants

const double PI = 3.14159; readonly int MaxUsers = 100;
📘 ការពន្យល់៖: const ជាតម្លៃថេរពេល compile។ readonly អាចកំណត់នៅ runtime ក្នុង constructor។

3. Operators

3.1 Arithmetic

int sum = 5 + 3; // 8 int mod = 10 % 3; // 1 double pow = Math.Pow(2, 3); // 8

3.2 Comparison

== != > < >= <=

3.3 Logical

&& // AND || // OR ! // NOT

3.4 Null-Coalescing

string name = null; string result = name ?? "Guest"; // "Guest" // Null-conditional int? length = name?.Length;
📘 ការពន្យល់៖: ?? return តម្លៃខាងស្តាំ បើខាងឆ្វេងជា null។ ?. ចូលប្រើ member ដោយសុវត្ថិភាព (មិន throw exception បើ null)។

4. Control Flow

4.1 if / else

if (age >= 18) { Console.WriteLine("Adult"); } else if (age >= 13) { Console.WriteLine("Teen"); } else { Console.WriteLine("Child"); }

4.2 switch

switch (day) { case 1: Console.WriteLine("Monday"); break; case 2: Console.WriteLine("Tuesday"); break; default: Console.WriteLine("Unknown"); break; }

4.3 Loops

for (int i = 0; i < 5; i++) { Console.Write(i + " "); } int j = 0; while (j < 5) { j++; } do { j++; } while (j < 10);

4.4 foreach

int[] nums = {1, 2, 3}; foreach (int n in nums) { Console.WriteLine(n); }
📘 ការពន្យល់៖: foreach ជា loop ពិសេសសម្រាប់ arrays និង collections។ ខ្លី និងសុវត្ថិភាពជាង for។

5. Methods

5.1 Basics

static void Greet() { Console.WriteLine("Hello!"); }

5.2 Parameters & Return

static int Add(int a, int b) { return a + b; }

5.3 Overloading

static int Add(int a, int b) { return a + b; } static double Add(double a, double b) { return a + b; }

5.4 Optional & params

// Optional parameters static void Greet(string name = "Guest") { Console.WriteLine("Hello, " + name); } // params (variable arguments) static int Sum(params int[] nums) { int total = 0; foreach (int n in nums) total += n; return total; } Sum(1, 2, 3, 4); // 10
📘 ការពន្យល់៖: params អនុញ្ញាតឲ្យបញ្ជូន arguments ច្រើនជា array។ optional parameter មាន default value។

6. Arrays & Strings

6.1 Arrays

int[] nums = {1, 2, 3}; Console.WriteLine(nums[0]); // 1 Console.WriteLine(nums.Length); // 3

6.2 2D Arrays

int[,] matrix = { {1,2}, {3,4} }; Console.WriteLine(matrix[1, 0]); // 3

6.3 Strings

string name = "Dara"; string greeting = $"Hello, {name}!"; // Interpolation // Verbatim string string path = @"C:\Users\Dara";

6.4 String Methods

name.Length // 4 name.ToUpper() // DARA name.ToLower() // dara name.Substring(0, 2) // Da name.Contains("ar") // true name.Replace("a", "A") // DArA
📘 ការពន្យល់៖: String interpolation $"..." ងាយស្រួលជាង concatenation។ Verbatim string @"..." មិនបកប្រែ escape characters។

7. OOP - Classes

7.1 Classes & Objects

class Student { public string Name; public int Age; public void Greet() { Console.WriteLine($"Hi, I'm {Name}"); } } Student s1 = new Student(); s1.Name = "Dara"; s1.Greet();

7.2 Constructors

class Student { public string Name; public Student(string name) { Name = name; } }

7.3 Properties

class Person { private int age; public int Age { get { return age; } set { if (value >= 0) age = value; } } // Auto-property public string Name { get; set; } }

7.4 static

class Counter { public static int Count = 0; public Counter() { Count++; } }
📘 ការពន្យល់៖: C# ប្រើ properties ជំនួស getter/setter methods។ auto-property { get; set; } ខ្លី និងងាយស្រួល។

8. Inheritance & Polymorphism

8.1 Inheritance

class Animal { public void Eat() { Console.WriteLine("Eating"); } } class Dog : Animal { public void Bark() { Console.WriteLine("Woof"); } }

8.2 virtual / override

class Animal { public virtual void Sound() { Console.WriteLine("..."); } } class Dog : Animal { public override void Sound() { Console.WriteLine("Woof!"); } }

8.3 Abstract

abstract class Shape { public abstract double Area(); } class Circle : Shape { public double Radius { get; set; } public override double Area() { return Math.PI * Radius * Radius; } }

8.4 Interfaces

interface IFlyable { void Fly(); } class Bird : IFlyable { public void Fly() { Console.WriteLine("Flying!"); } }
📘 ការពន្យល់៖: C# ប្រើ : សម្រាប់ inheritance។ virtual ឲ្យ override បាន។ abstract មិនអាចបង្កើត object ផ្ទាល់។ Interface ជាកិច្ចសន្យា។

9. Collections

9.1 List<T>

using System.Collections.Generic; List<string> names = new List<string>(); names.Add("Dara"); names.Add("Sok"); names[0]; // Dara names.Count; // 2

9.2 Dictionary

Dictionary<string, int> ages = new(); ages["Dara"] = 20; ages["Dara"]; // 20

9.3 HashSet

HashSet<int> nums = new HashSet<int>(); nums.Add(1); nums.Add(1); // មិនបន្ថែមទេ (duplicate)

9.4 LINQ

using System.Linq; var adults = people .Where(p => p.Age >= 18) .OrderBy(p => p.Name) .Select(p => p.Name) .ToList();
📘 ការពន្យល់៖: List<T> ជា array ដែលអាចបត់បែន។ Dictionary ជា key-value។ LINQ ជាមុខងារដ៏មានឥទ្ធិឫទ្ធិសម្រាប់ query collections។

10. Generics

10.1 Generic Classes

class Box<T> { private T value; public void Set(T value) { this.value = value; } public T Get() { return value; } } Box<string> b = new Box<string>(); b.Set("Hello");

10.2 Generic Methods

static void Print<T>(T item) { Console.WriteLine(item); }

10.3 Constraints

static void Print<T>(T item) where T : class { Console.WriteLine(item); }
📘 ការពន្យល់៖: Generics អនុញ្ញាតឲ្យសរសេរ code ដែលដំណើរការជាមួយ type ណាមួយ ដោយរក្សា type safety និង performance។

11. Exception Handling

11.1 try / catch

try { int result = 10 / 0; } catch (DivideByZeroException ex) { Console.WriteLine("Error: " + ex.Message); }

11.2 finally

try { // risky code } catch (Exception ex) { Console.WriteLine(ex.Message); } finally { Console.WriteLine("Always runs"); }

11.3 Custom Exception

class MyException : Exception { public MyException(string message) : base(message) { } } throw new MyException("Something went wrong");
📘 ការពន្យល់៖: C# ប្រើ try-catch-finally។ ចាប់ exception ជាក់លាក់មុន exception ទូទៅ (Exception)។ បង្កើត custom exception ដោយស្នងពី Exception។

12. File I/O

12.1 Read File

using System.IO; string content = File.ReadAllText("data.txt"); Console.WriteLine(content);

12.2 Write File

File.WriteAllText("data.txt", "Hello, File!");

12.3 StreamReader/Writer

using (StreamWriter writer = new StreamWriter("data.txt")) { writer.WriteLine("Line 1"); writer.WriteLine("Line 2"); } using (StreamReader reader = new StreamReader("data.txt")) { string line; while ((line = reader.ReadLine()) != null) { Console.WriteLine(line); } }
📘 ការពន្យល់៖: File.ReadAllText / WriteAllText ខ្លីសម្រាប់ file តូច។ using block បិទ resource ដោយស្វ័យប្រវត្តិ។

13. Async / Await

13.1 async / await

async Task<string> GetDataAsync() { using var client = new HttpClient(); string result = await client.GetStringAsync("https://api.example.com"); return result; } string data = await GetDataAsync();

13.2 Task

Task.Run(() => { Console.WriteLine("Running in background"); }); Task<int> task = Task.Run(() => 42); int result = await task;
📘 ការពន្យល់៖: async/await ធ្វើឲ្យកូដ asynchronous មើលទៅដូច synchronous។ ល្អសម្រាប់ I/O, network, និង database។

14. Modern C#

14.1 Lambda

Func<int, int, int> add = (a, b) => a + b; Console.WriteLine(add(2, 3)); // 5

14.2 Pattern Matching

object obj = 42; if (obj is int n) { Console.WriteLine($"It's an int: {n}"); } string result = obj switch { int i => $"Integer: {i}", string s => $"String: {s}", _ => "Unknown" };

14.3 Records

public record Person(string Name, int Age); var p = new Person("Dara", 20); Console.WriteLine(p); // Person { Name = Dara, Age = 20 }

14.4 Nullable Types

int? age = null; if (age.HasValue) { Console.WriteLine(age.Value); }
📘 ការពន្យល់៖: record សម្រាប់ immutable data។ pattern matching សរសេរ code ខ្លី និងច្បាស់។ ? បន្ទាប់ពី type ធ្វើឲ្យវាអាចជា null។

15. C# Project

សាកល្បងបង្កើតកម្មវិធី Student Manager តូចមួយ៖

using System; using System.Collections.Generic; using System.Linq; public class Student { public string Name { get; set; } public int Age { get; set; } public override string ToString() { return $"{Name} ({Age})"; } } class Program { static void Main() { List<Student> students = new List<Student> { new Student { Name = "Dara", Age = 20 }, new Student { Name = "Sok", Age = 22 }, new Student { Name = "Anna", Age = 19 } }; // Filter + Sort with LINQ var sorted = students .Where(s => s.Age >= 20) .OrderBy(s => s.Age) .ToList(); foreach (var s in sorted) { Console.WriteLine(s); } } }
📘 ការពន្យល់៖: គម្រោងនេះប្រើ class, auto-properties, List, LINQ (Where, OrderBy), និង ToString() override។ សាកល្បងបន្ថែម៖ Add, Remove, ឬ Search functionality។
គន្លឹះ៖: សាកល្បងគម្រោងតូចៗ — Todo List, Calculator, Bank System, ឬ Game តូចៗជាមួយ Unity ដើម្បីយល់ C# លឿនជាងអានទ្រឹស្តី។
