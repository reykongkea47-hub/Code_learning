1. HTML Introduction - ការណែនាំ HTML

1.1 អ្វីជា HTML?

HTML (HyperText Markup Language) គឺជាភាសាសម្រាប់បង្កើតរចនាសម្ព័ន្ធនៃគេហទំព័រ។

📘 ការពន្យល់៖ HTML គឺជា មូលដ្ឋានគ្រឹះ នៃគេហទំព័រ។ វាកំណត់ថាតើមានអ្វីនៅលើទំព័រ — ចំណងជើង អត្ថបទ រូបភាព តំណភ្ជាប់ ជាដើម។ វាមិនមែនជាភាសាសរសេរកម្មវិធី (programming language) ទេ តែជាភាសា markup ដែលប្រើ tags ដើម្បីសម្គាល់អត្ថន័យ។

1.2 រចនាសម្ព័ន្ធ HTML

<!DOCTYPE html> <html> <head> <title>ចំណងជើងទំព័រ</title> </head> <body> <h1>សូមស្វាគមន៍!</h1> </body> </html>
📘 ការពន្យល់៖
  • <!DOCTYPE html> — ប្រាប់ browser ថាជា HTML5
  • <html> — ធាតុឫស (root)
  • <head> — ព័ត៌មានមេតា (មិនបង្ហាញ)
  • <body> — ខ្លឹមសារដែលបង្ហាញ

1.3 ទំព័រដំបូង

<!DOCTYPE html> <html lang="km"> <head> <meta charset="UTF-8"> <title>Hello</title> </head> <body> <h1>សូមស្វាគមន៍មកកាន់ HTML</h1> </body> </html>

1.4 Comment

<!-- នេះគឺជា comment -->
📘 ការពន្យល់៖ Comment មិនត្រូវបានបង្ហាញនៅលើ browser ទេ។ ប្រើសម្រាប់កត់ត្រា ឬពន្យល់កូដ។

2. Basic Tags - ធាតុមូលដ្ឋាន

2.1 Headings

<h1>ចំណងជើង 1</h1> <h2>ចំណងជើង 2</h2> <h3>ចំណងជើង 3</h3>
📘 ការពន្យល់៖ មាន <h1> ដល់ <h6> ។ <h1> ធំបំផុត ហើយ <h6> តូចបំផុត។ ប្រើសម្រាប់ចំណងជើង និងរចនាសម្ព័ន្ធទំព័រ។

2.2 Paragraph

<p>នេះគឺជាកថាខណ្ឌមួយ។</p>
📘 ការពន្យល់៖: <p> បង្កើតកថាខណ្ឌ (paragraph)។ Browser បន្ថែមចន្លោះខាងលើ និងខាងក្រោមដោយស្វ័យប្រវត្តិ។

2.3 Line Break

បន្ទាត់ទី 1<br> បន្ទាត់ទី 2

2.4 Horizontal Rule

<hr>
📘 ការពន្យល់៖: <br> បំបែកបន្ទាត់។ <hr> បង្កើតបន្ទាត់ផ្ដេកសម្រាប់បែងចែកផ្នែក។ ទាំងពីរជា void element (គ្មាន closing tag)។

3. Text Formatting - ការតុបតែងអក្សរ

3.1 Bold & Strong

<b>Bold</b> <strong>សំខាន់</strong>
📘 ការពន្យល់៖: <b> ធ្វើអក្សរដិត (មិនបញ្ជាក់អត្ថន័យ)។ <strong> ក៏ដិតដែរ ប៉ុន្តែបញ្ជាក់ថាសំខាន់ (semantic)។ ប្រើ <strong> ល្អជាងសម្រាប់ SEO។

3.2 Italic & Em

<i>Italic</i> <em>សង្កត់ធ្ងន់</em>

3.3 Underline

<u>គូសបន្ទាត់ក្រោម</u>

3.4 Mark & Small

<mark>បន្លិច</mark> <small>អក្សរតូច</small>
📘 ការពន្យល់៖: <mark> បន្លិចអត្ថបទដូច highlighter។ <small> បង្ហាញអក្សរតូចជាងធម្មតា។

4. Links & Images

4.1 Anchor Tags

<a href="https://example.com">ចុចទីនេះ</a>
📘 ការពន្យល់៖: <a> បង្កើតតំណភ្ជាប់។ href ជាគោលដៅ។ អាចភ្ជាប់ទៅទំព័រផ្សេង ឬផ្នែកក្នុងទំព័រតែមួយ (#id)។

4.2 Target Attribute

<a href="https://example.com" target="_blank">បើកផ្ទាំងថ្មី</a>

4.3 Images

<img src="logo.png" alt="រូបសញ្ញា">
📘 ការពន្យល់៖: <img> បង្ហាញរូបភាព។ src ជាផ្លូវទៅរូប, alt ជាអត្ថបទជំនួស នៅពេលរូបមិនអាចបង្ហាញ។

4.4 Alt Text

📘 ការពន្យល់៖: alt មានប្រយោជន៍សម្រាប់ accessibility (អ្នកមើលពិការភ្នែក) និង SEO។ គួរសរសេរឲ្យពិពណ៌នាច្បាស់។

5. Lists - បញ្ជី

5.1 Unordered List

<ul> <li>ចំណុច 1</li> <li>ចំណុច 2</li> </ul>

5.2 Ordered List

<ol> <li>ទីមួយ</li> <li>ទីពីរ</li> </ol>

5.3 Description List

<dl> <dt>HTML</dt> <dd>ភាសាបង្កើតគេហទំព័រ</dd> </dl>
📘 ការពន្យល់៖: <ul> បញ្ជីគ្មានលេខ (bullet)។ <ol> បញ្ជីមានលេខ។ <dl> បញ្ជីពន្យល់ (term + description)។

6. Tables - តារាង

6.1 Basic Table

<table> <tr> <th>ឈ្មោះ</th> <th>អាយុ</th> </tr> <tr> <td>Dara</td> <td>20</td> </tr> </table>
📘 ការពន្យល់៖: <table> បង្កើតតារាង។ <tr> ជួរដេក, <th> ក្បាលតារាង, <td> ទិន្នន័យ។

6.2 thead & tbody

<table> <thead> <tr><th>ឈ្មោះ</th></tr> </thead> <tbody> <tr><td>Dara</td></tr> </tbody> </table>

6.3 Colspan & Rowspan

<td colspan="2">រួមពីរជួរឈរ</td>
📘 ការពន្យល់៖: colspan បញ្ចូលជួរឈរ, rowspan បញ្ចូលជួរដេក។ ប្រើសម្រាប់ header ឬ cell ពិសេស។

7. Forms - ទម្រង់បញ្ចូល

7.1 Form Basics

<form action="/submit" method="post"> <!-- ធាតុបញ្ចូល --> </form>

7.2 Input Types

<input type="text" name="name"> <input type="email"> <input type="password"> <input type="checkbox"> <input type="radio"> <input type="submit" value="បញ្ជូន">

7.3 Labels

<label for="email">អ៊ីមែល</label> <input type="email" id="email">

7.4 Select & Textarea

<select> <option>ជម្រើស 1</option> <option>ជម្រើស 2</option> </select> <textarea rows="4"></textarea>
📘 ការពន្យល់៖: Form ប្រើសម្រាប់បញ្ចូលទិន្នន័យ។ <label> ភ្ជាប់ជាមួយ input តាម for និង id ដើម្បីភាពងាយស្រួលក្នុងការចុច។

8. Semantic HTML - អត្ថន័យ

8.1 header & footer

<header>... ក្បាលទំព័រ</header> <footer>... ជើងទំព័រ</footer>

8.2 nav & main

<nav>... ម៉ឺនុយ</nav> <main>... ខ្លឹមសារចម្បង</main>

8.3 section & article

<section>... ផ្នែកមួយ</section> <article>... អត្ថបទមួយ</article>

8.4 aside

<aside>... ព័ត៌មានបន្ថែម</aside>
📘 ការពន្យល់៖: Semantic HTML ប្រើ tags ដែលបញ្ជាក់អត្ថន័យ ជំនួស <div>។ វាជួយ SEO និងភាពងាយស្រួលអានកូដ។

9. Multimedia

9.1 Audio

<audio controls> <source src="song.mp3" type="audio/mpeg"> </audio>

9.2 Video

<video controls width="400"> <source src="clip.mp4" type="video/mp4"> </video>

9.3 iframe

<iframe src="https://example.com"></iframe>
📘 ការពន្យល់៖: <audio> និង <video> បង្ហាញមេឌៀ។ controls បន្ថែមប៊ូតុង play/pause។ <iframe> បង្កប់ទំព័រផ្សេងក្នុងទំព័ររបស់អ្នក (ដូច YouTube)។

10. Attributes - គុណលក្ខណៈ

10.1 Global Attributes

  • id — សម្គាល់តែមួយគត់
  • class — ចងជាក្រុម
  • style — កំណត់ CSS ផ្ទាល់
  • title — អត្ថបទពន្យល់
  • hidden — លាក់ធាតុ

10.2 id & class

<div id="header" class="box large"></div>
📘 ការពន្យល់៖: id ត្រូវតែមានតែមួយក្នុងទំព័រ។ class អាចប្រើច្រើនដង។ ប្រើក្នុង CSS ដើម្បីកំណត់ style។

10.3 data-*

<div data-user-id="123"></div>
📘 ការពន្យល់៖: data-* ផ្ទុកទិន្នន័យផ្ទាល់ខ្លួន ដែល JavaScript អាចអានបាន។

11. Meta Tags & SEO

11.1 Charset

<meta charset="UTF-8">

11.2 Viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0">

11.3 Description

<meta name="description" content="រៀន HTML ជាភាសាខ្មែរ">
📘 ការពន្យល់៖: Meta tags ផ្តល់ព័ត៌មានអំពីទំព័រ។ charset កំណត់ encoding (UTF-8 គាំទ្រខ្មែរ)។ viewport សម្រាប់ responsive។ description បង្ហាញលើលទ្ធផលស្វែងរក។

12. HTML5 New Elements

12.1 figure

<figure> <img src="pic.jpg" alt="រូបភាព"> <figcaption>ការពិពណ៌នា</figcaption> </figure>

12.2 details

<details> <summary>ចុចមើល</summary> ខ្លឹមសារលាក់ </details>

12.3 progress

<progress value="70" max="100"></progress>
📘 ការពន្យល់៖: <figure> ភ្ជាប់រូបភាព + caption។ <details> បង្កើត accordion គ្មាន JavaScript។ <progress> បង្ហាញរបារភាគរយ។

13. Block vs Inline

13.1 Block

div, p, h1-h6, section, article — យកទទឹងពេញ និងចាប់ជួរថ្មី។

13.2 Inline

span, a, b, i, em, strong — យកទទឹងតាមខ្លឹមសារ និងមិនចាប់ជួរថ្មី។

13.3 Inline-block

ប្រើ display: inline-block ដើម្បីឲ្យដូច inline ប៉ុន្តែកំណត់ width/height បាន។

📘 ការពន្យល់៖: Block elements បង្កើតប្លុកថ្មី ខណៈ Inline elements នៅជាប់គ្នា។ ការយល់ពីភាពខុសគ្នានេះ ជួយក្នុងការរៀបចំ layout។

14. Best Practices

  • ប្រើ Semantic tags ជំនួស <div>
  • ដាក់ alt លើរូបភាពទាំងអស់
  • ប្រើ label ភ្ជាប់ជាមួយ input
  • រក្សា indentation ឲ្យស្អាត
  • ប្រើ meta viewport សម្រាប់ responsive
  • Validate HTML ជាមួយ W3C Validator
📘 ការពន្យល់៖: កូដ HTML ល្អ មិនត្រឹមតែដំណើរការបានទេ តែត្រូវអានងាយ ថែទាំងាយ និង SEO ល្អ។
