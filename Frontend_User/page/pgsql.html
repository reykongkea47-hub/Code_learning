PostgreSQL Tutorial - ការណែនាំ PostgreSQL

PostgreSQL គឺជាប្រព័ន្ធគ្រប់គ្រង database ប្រភេទ object-relational ដែលមានអាយុកាលជាង 35 ឆ្នាំ និងត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយក្នុងពិភពលោក។

📘 ការពន្យល់៖: PostgreSQL គឺ open-source, ឥតគិតថ្លៃ, មានសុវត្ថិភាពខ្ពស់, គាំទ្រ ACID និងមាន features ជាច្រើនដូចជា JSON, full-text search, និង window functions។

PostgreSQL Intro

PostgreSQL (ហៅកាត់ថា Postgres) ត្រូវបានបង្កើតឡើងនៅ UC Berkeley ក្នុងឆ្នាំ 1986។

  • ✅ គាំទ្រ SQL ពេញលេញ
  • ✅ ACID compliant
  • ✅ គាំទ្រ JSON / JSONB
  • ✅ Cross-platform

PostgreSQL Install

ទាញយកពី postgresql.org រួចដំឡើងតាមប្រព័ន្ធប្រតិបត្តិការរបស់អ្នក៖

# Ubuntu / Debian sudo apt install postgresql postgresql-contrib # MacOS brew install postgresql # Windows # ទាញយក installer ពី postgresql.org

PostgreSQL Get Started

ចាប់ផ្តើមជាមួយ PostgreSQL៖

# ចូលទៅ PostgreSQL psql -U postgres # បង្កើត database CREATE DATABASE mydb; # ជ្រើស database \c mydb

PostgreSQL pgAdmin 4

pgAdmin 4 គឺជា GUI tool ដ៏ពេញនិយមសម្រាប់គ្រប់គ្រង PostgreSQL។

  • ទាញយកពី pgadmin.org
  • ភ្ជាប់ទៅ server: localhost:5432
  • គ្រប់គ្រង database, tables, queries

Database - គ្រប់គ្រង Database

CREATE TABLE

CREATE TABLE users ( id SERIAL PRIMARY KEY, name VARCHAR(100) NOT NULL, email VARCHAR(150) UNIQUE, age INT, created_at TIMESTAMP DEFAULT NOW() );

INSERT INTO

INSERT INTO users (name, email, age) VALUES ('Dara', 'dara@example.com', 20); INSERT INTO users (name, email, age) VALUES ('Sok', 'sok@example.com', 22), ('Anna', 'anna@example.com', 19);

Fetch Data

SELECT * FROM users; SELECT name, email FROM users;

ADD COLUMN

ALTER TABLE users ADD COLUMN phone VARCHAR(20);

UPDATE

UPDATE users SET age = 21 WHERE name = 'Dara';

ALTER COLUMN

ALTER TABLE users ALTER COLUMN name TYPE VARCHAR(200);

DROP COLUMN

ALTER TABLE users DROP COLUMN phone;

DELETE

DELETE FROM users WHERE age < 18;

DROP TABLE

DROP TABLE users;

PostgreSQL Syntax & Operators

Operators

Operatorនិយមន័យ
=ស្មើ
<> ឬ !=មិនស្មើ
>, <ធំ / តូច
LIKEផ្គូផ្គង pattern
INស្ថិតក្នុងបញ្ជី
BETWEENក្នុងចន្លោះ

SELECT

SELECT * FROM users;

SELECT DISTINCT

SELECT DISTINCT age FROM users;

WHERE

SELECT * FROM users WHERE age > 18;

ORDER BY

SELECT * FROM users ORDER BY age DESC;

LIMIT

SELECT * FROM users LIMIT 10;

MIN and MAX

SELECT MIN(age), MAX(age) FROM users;

COUNT

SELECT COUNT(*) FROM users;

SUM

SELECT SUM(price) FROM orders;

AVG

SELECT AVG(age) FROM users;

LIKE

SELECT * FROM users WHERE name LIKE 'D%';

IN

SELECT * FROM users WHERE age IN (18, 20, 25);

BETWEEN

SELECT * FROM users WHERE age BETWEEN 18 AND 30;

AS

SELECT name AS username, age AS user_age FROM users;

PostgreSQL Joins

JOIN ត្រូវបានប្រើសម្រាប់ភ្ជាប់តារាងច្រើនចូលគ្នា។

INNER JOIN

SELECT u.name, o.total FROM users u INNER JOIN orders o ON u.id = o.user_id;

LEFT JOIN

SELECT u.name, o.total FROM users u LEFT JOIN orders o ON u.id = o.user_id;

RIGHT JOIN

SELECT u.name, o.total FROM users u RIGHT JOIN orders o ON u.id = o.user_id;

FULL JOIN

SELECT u.name, o.total FROM users u FULL OUTER JOIN orders o ON u.id = o.user_id;

CROSS JOIN

SELECT * FROM colors CROSS JOIN sizes;

PostgreSQL Advanced

UNION

SELECT name FROM users UNION SELECT name FROM customers;

GROUP BY

SELECT age, COUNT(*) FROM users GROUP BY age;

HAVING

SELECT age, COUNT(*) FROM users GROUP BY age HAVING COUNT(*) > 5;

EXISTS

SELECT * FROM users u WHERE EXISTS ( SELECT 1 FROM orders WHERE user_id = u.id );

ANY

SELECT * FROM users WHERE age > ANY (SELECT age FROM users WHERE age > 25);

ALL

SELECT * FROM users WHERE age > ALL (SELECT age FROM users WHERE age < 20);

CASE

SELECT name, CASE WHEN age < 18 THEN 'Minor' WHEN age < 60 THEN 'Adult' ELSE 'Senior' END AS category FROM users;
