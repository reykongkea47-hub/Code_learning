1. សេចក្តីផ្តើម Tailwind CSS

1.1 តើ Tailwind CSS គឺជាអ្វី?

Tailwind CSS គឺជា CSS Utility Framework ដែលអនុញ្ញាតឱ្យអ្នកសរសេរ CSS ដោយប្រើ class ដែលមានរួចរាល់ក្នុង HTML។

📘 ការពន្យល់៖ ជាធម្មតា អ្នកត្រូវសរសេរ CSS ដោយឡែក ដូចជា .btn { padding: 10px; }។ ប៉ុន្តែ Tailwind អនុញ្ញាតឱ្យអ្នកប្រើ class ដែលមានស្រាប់ ដូចជា px-4 py-2 bg-blue-500 ដោយផ្ទាល់ក្នុង HTML។ នេះធ្វើឱ្យកូដខ្លី និងលឿនជាង។

1.2 ហេតុអ្វីបានជាប្រើ Tailwind CSS?

  • រហ័ស — មិនចាំបាច់សរសេរ CSS ច្រើន
  • Responsive — ងាយស្រួលធ្វើឱ្យទាក់ទងនឹងគ្រប់ទំហំអេក្រង់
  • Customizable — អាចកែប្រែតាមតម្រូវការ
  • Popular — ប្រើប្រាស់យ៉ាងទូលំទូលាយក្នុងឧស្សាហកម្ម

1.3 ការដំឡើង

វិធី ១៖ ប្រើ CDN (ងាយស្រួលបំផុត)

<script src="https://cdn.tailwindcss.com"></script>

វិធី ២៖ ដំឡើងក្នុងគម្រោង

npm install -D tailwindcss npx tailwindcss init

1.4 ឧទាហរណ៍ដំបូង

<!DOCTYPE html> <html> <head> <script src="https://cdn.tailwindcss.com"></script> </head> <body class="bg-gray-100 p-8"> <h1 class="text-3xl font-bold text-blue-600"> សួស្តី Tailwind CSS! </h1> </body> </html>
គន្លឹះ៖ Tailwind ល្អសម្រាប់អ្នកដែលចូលចិត្តសរសេរ markup ជាមួយ styles តែម្តង។ បើអ្នកចូលចិត្ត CSS បែបប្រពៃណី អាចប្រើបានដែរ — វាមាន @apply សម្រាប់បង្កើត custom classes។

Padding ទៅទិសដៅជាក់លាក់

4.2 Margin (ការបែងចែកក្រៅ)

  • m-4 — margin 16px គ្រប់ទិស
  • mx-auto — ឆ្វេង និងស្តាំ auto (កណ្តាល)
  • mt-4 / mb-4 — លើ / ក្រោម
  • ml-4 / mr-4 — ឆ្វេង / ស្តាំ
<div class="mx-auto max-w-md"> ប្រអប់ដែលនៅកណ្តាល </div>

4.3 Gap (ចន្លោះរវាងធាតុ)

4.4 Width & Height

  • w-full — 100% ទទឹង

10.3 Dark Mode
