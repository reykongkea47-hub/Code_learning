1.1 អ្វីជា Python?

  • Data Science — NumPy, Pandas
  • Machine Learning — TensorFlow, PyTorch
  • Web Development — Django, Flask
  • Automation — Scripts, Bots
  • AI & Chatbots

4. Control Flow

4.1 if / elif / else

if age >= 18: print("Adult") elif age >= 13: print("Teen") else: print("Child")
📘 ការពន្យល់៖: Python ប្រើ indentation (4 spaces ជាទូទៅ) សម្រាប់ block។ មិនប្រើ { } ដូច C/Java។

4.2 match / case

match day: case 1: print("Monday") case 2: print("Tuesday") case _: print("Unknown")

4.3 Loops

# for loop for i in range(5): print(i) # while loop i = 0 while i < 5: print(i) i += 1

4.4 Comprehensions

# List comprehension squares = [n**2 for n in range(5)] # [0, 1, 4, 9, 16] # មាន condition evens = [n for n in range(10) if n % 2 == 0] # Dict comprehension squares = {n: n**2 for n in range(3)}
📘 ការពន្យល់៖: Comprehensions ជាមុខងារពិសេសរបស់ Python។ វាបង្កើត list/dict/set ក្នុងបន្ទាត់តែមួយ ជំនួស loop ធម្មតា។ លឿន និងស្អាតជាង។

5. Functions

5.1 Basics

def greet(): print("Hello!") greet()

5.2 Parameters & Return

def add(a, b): return a + b result = add(2, 3) # 5 # Default parameter def greet(name="Guest"): return f"Hello, {name}!"

5.3 Lambda

# Anonymous function add = lambda a, b: a + b add(2, 3) # 5 # ប្រើជាមួយ sort users = [{"name": "Dara", "age": 20}] users.sort(key=lambda u: u["age"])

5.4 Decorators

def uppercase(func): def wrapper(*args): result = func(*args) return result.upper() return wrapper @uppercase def greet(name): return f"Hello, {name}" greet("Dara") # "HELLO, DARA"
📘 ការពន្យល់៖: Decorator ជា function ដែល "wrap" function ផ្សេង ដើម្បីបន្ថែម functionality ដោយមិនកែ function ដើម។ ប្រើ @decorator_name។

6. Lists, Tuples, Sets, Dictionaries

6.1 Lists

nums = [1, 2, 3] nums.append(4) # [1, 2, 3, 4] nums.insert(0, 0) # [0, 1, 2, 3, 4] nums.remove(2) # [0, 1, 3, 4] nums.pop() # ដកចេញ element ចុងក្រោយ len(nums) # ចំនួន element

6.2 Tuples

point = (3, 4) x, y = point # unpacking # tuple មិនអាចផ្លាស់ប្តូរ (immutable)
📘 ការពន្យល់៖: Tuple ដូច List ប៉ុន្តែ immutable (មិនអាចកែ)។ ប្រើសម្រាប់ data ដែលមិនគួរផ្លាស់ប្តូរ ដូចជា coordinates, RGB colors។ លឿនជាង List។

6.3 Sets

nums = {1, 2, 3} nums.add(4) nums.add(1) # មិនបន្ថែមទេ (duplicate) # Set operations a = {1, 2, 3} b = {3, 4, 5} a | b # union a & b # intersection a - b # difference

6.4 Dictionaries

user = {"name": "Dara", "age": 20} user["name"] # "Dara" user.get("age") # 20 user.keys() # keys user.values() # values user.items() # key-value pairs for key, val in user.items(): print(key, val)
📘 ការពន្យល់៖: Dict ជា collection នៃ key-value។ Key ត្រូវតែ unique និង immutable។ ប្រើ .get() ជំនួស [] ដើម្បីជៀសវាង KeyError។

s = "Hello, World!" s.upper() # HELLO, WORLD! s.lower() # hello, world! s.split(", ") # ["Hello", "World!"] s.replace("World", "Python") s.strip() # លុប space ចុងចុង s.startswith("Hello") # True s.find("World") # 7

s = "Python" s[0] # 'P' s[-1] # 'n' s[1:4] # 'yth' s[:3] # 'Pyt' s[3:] # 'hon' s[::2] # 'Pto' s[::-1] # 'nohtyP' (reverse)

9. OOP - Classes

9.1 Classes & Objects

class Student: def greet(self): return f"Hi, I'm {self.name}" s1 = Student() s1.name = "Dara" s1.greet()

9.2 __init__

class Student: def __init__(self, name, age): self.name = name self.age = age s1 = Student("Dara", 20)

9.3 Inheritance

class Animal: def eat(self): print("Eating") class Dog(Animal): def bark(self): print("Woof") d = Dog() d.eat() # ទទួលពី Animal d.bark() # របស់ Dog

9.4 Dunder Methods

class Point: def __init__(self, x, y): self.x = x self.y = y def __str__(self): return f"({self.x}, {self.y})" def __add__(self, other): return Point(self.x + other.x, self.y + other.y) p = Point(1, 2) print(p) # (1, 2)
📘 ការពន្យល់៖: self ជា reference ទៅ object បច្ចុប្បន្ន។ __init__ ជា constructor។ Dunder methods (double underscore) ដូច __str__, __add__ កំណត់ behavior របស់ object។

11. Error Handling

11.1 try / except

try: result = 10 / 0 except ZeroDivisionError as e: print(f"Error: {e}") except Exception as e: print(f"Unknown: {e}")

def divide(a, b): if b == 0: raise ValueError("Cannot divide by zero") return a / b

13. Advanced Topics

13.1 *args / **kwargs

def sum_all(*args): return sum(args) sum_all(1, 2, 3, 4) # 10 def show(**kwargs): for key, val in kwargs.items(): print(key, val) show(name="Dara", age=20)

13.2 Context Manager

class MyFile: def __init__(self, filename): self.filename = filename def __enter__(self): self.file = open(self.filename) return self.file def __exit__(self, *args): self.file.close()

13.3 Virtual Environment

# បង្កើត virtual environment python -m venv myenv # Activate # Windows: myenv\Scripts\activate # Mac/Linux: source myenv/bin/activate # Deactivate deactivate
📘 ការពន្យល់៖: Virtual environment ជាប្រអប់ដែលរក្សា packages ដោយឡែកសម្រាប់គម្រោងនីមួយៗ ដើម្បីជៀសវាងបញ្ហា version conflict។

15. Python Project

សាកល្បងបង្កើត Todo List តូចមួយ៖

import json import os TODO_FILE = "todos.json" def load_todos(): if os.path.exists(TODO_FILE): with open(TODO_FILE) as f: return json.load(f) return [] def save_todos(todos): with open(TODO_FILE, "w") as f: json.dump(todos, f, indent=2) def add_todo(todos, text): todos.append({"id": len(todos) + 1, "text": text, "done": False}) save_todos(todos) print(f"✅ Added: {text}") def list_todos(todos): if not todos: print("📋 No todos yet") return for todo in todos: status = "✅" if todo["done"] else "⬜" print(f"{status} [{todo['id']}] {todo['text']}") def main(): todos = load_todos() add_todo(todos, "រៀន Python") add_todo(todos, "ធ្វើលំហាត់") list_todos(todos) if __name__ == "__main__": main()
📘 ការពន្យល់៖: គម្រោងនេះប្រើ function, list, dict, file I/O និង JSON។ សាកល្បងបន្ថែម៖ menu, delete, mark as done, ឬ user input។
គន្លឹះ៖: Python ល្អសម្រាប់អ្នកចង់ចាប់ផ្តើម programming និងធ្វើគម្រោងជាក់ស្តែង។ សាកល្បងគម្រោងតូចៗ — Calculator, Weather App, Web Scraper, ឬ Bot Telegram។
